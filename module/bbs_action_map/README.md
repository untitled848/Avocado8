# 지역 탐색 (`bbs_action_map`)

게시판(또는 타임라인)에서 캐릭터가 **지역을 이동**하고, 이동 중 **이벤트**(아이템·화폐·강제이동·몬스터)를 만나는 모듈입니다.  
몬스터가 나온 글에는 **댓글(또는 타임라인 답글)** 로 공략할 수 있습니다.

위치와 탐색 횟수는 사이트 전체에서 공유됩니다. 게시판마다 맵이 갈라지지는 않습니다.  
글쓰기에서만 **지역 탐색** 액션이 나옵니다. 일반 댓글용 스코프는 없습니다. (몬스터 공략만 예외)

---

## 켜는 순서

1. 관리자 → **모듈**에서 **지역 탐색**을 활성화합니다.
2. 쓸 게시판(또는 타임라인) 설정의 모듈에서 **지역 탐색**의 글(write)을 켭니다. (기본값은 꺼짐)
3. **탐색 설정**에서 횟수 방식·분기·전체 맵 이미지를 정합니다.
4. **맵 관리**에서 지역을 만들고 **사용**을 켠 뒤, **통행**으로 이어질 지역을 체크합니다.
5. (선택) 각 맵의 **이벤트**를 등록합니다. 없어도 이동만은 됩니다.
6. (선택) **캐릭터 위치**에서 초기 위치를 넣습니다. 위치가 없으면 처음 이동할 때 사용 중인 맵 전체를 고를 수 있습니다.

---

## 관리자 화면

주소: `관리자 → 모듈 → 지역 탐색` (`/adm_module/module.php?m=bbs_action_map&p=setting`)

### 탐색 설정

| 항목 | 하는 일 |
|------|---------|
| 탐색 방식 · 차감식 | 분기마다 카운터가 0으로 리셋되고, 탐색할 때마다 1씩 올라갑니다. 분기 최대 횟수에 닿으면 더 못 합니다. |
| 탐색 방식 · 누적식 | 분기마다 정해진 양만큼 쌓이고, 탐색할 때마다 1씩 깎입니다. 행동력처럼 씁니다. |
| 탐색 분기 | 매일 자정 / 매주 월요일 / 매월 1일 / N시간마다 |
| 탐색 가능 횟수 (차감식) | 한 분기에 캐릭터 1명이 시도할 수 있는 최대. **0이면 횟수 제한 없음** |
| 분기별 누적 · 최대 누적 (누적식) | 분기마다 더해지는 양과 상한 |
| 지역 정보 패널 | 글쓰기에서 맵을 고를 때 현재 지역 설명을 보여줄지 |
| 맵 이미지 | 목록 위에 전체 지도를 띄웁니다. 파일 업로드 또는 URL. 가로·세로는 업로드 시 비우면 자동 |

**모드(차감/누적)를 바꾸면 모든 캐릭터의 탐색 카운터가 새 모드 초기값으로 리셋됩니다.**

### 맵 관리

지역(구역) 목록입니다. 추가·수정에서 다음을 정합니다.

| 항목 | 하는 일 |
|------|---------|
| 사용 | 끄면 목적지로 고를 수 없습니다. |
| 이름 · 썸네일 · 설명 | 패널·로그에 보입니다. |
| 통행 | **이 맵에서 갈 수 있는** 다른 맵을 체크합니다. 체크하지 않으면 그쪽으로 이동할 수 없습니다. |
| X·Y·너비·높이 | 전체 맵 이미지가 있을 때만 나옵니다. 목록 위 지도의 클릭 영역입니다. |

목록에서 각 맵으로 **이벤트** 관리로 들어갈 수 있습니다.

### 이벤트 관리

지역을 고른 뒤, 그 지역에 도착했을 때 나올 결과를 만듭니다.  
100면체(0~100) 구간에 걸리면 그중 **하나**가 나옵니다. 구간이 겹치면 겹친 것 중 무작위로 고릅니다.

| 항목 | 하는 일 |
|------|---------|
| 사용하기 | 끄면 뽑히지 않습니다. |
| 이벤트타입 | 일반 / 아이템획득 / 화폐변동 / 지역이동 / 몬스터공격 |
| 이미지 · 텍스트 | 글 로그에 표시 |
| 획득 구간 | 예) 0~20 이면 대략 21% |
| 획득가능갯수 | 전역으로 몇 번까지 나올지. **0이면 무제한**. 현재획득갯수로 이미 나온 횟수를 봅니다. |

타입별 효과:

| 타입 | 결과 |
|------|------|
| 일반 | 문구·이미지만 |
| 아이템획득 | 지정 아이템을 인벤에 지급 |
| 화폐변동 | 포인트(사이트 화폐) 증감 |
| 지역이동 | 도착한 뒤 **다른 맵으로 강제 이동** |
| 몬스터공격 | 그 글에 몬스터가 붙고, 같은 위치의 캐릭터가 댓글로 공략 |

이벤트가 없거나 주사위가 빈 구간에 떨어지면 「구역으로 이동했다」만 남습니다.

### 캐릭터 위치

캐릭터마다 **지금 있는 맵**을 일괄로 바꿉니다. 이름·오너 아이디로 검색할 수 있습니다.

## 플레이어가 하는 일

### 위치 이동 (글쓰기)

지역 탐색이 켜진 게시판에서 **새 글**을 쓸 때 액션에서 **지역 탐색(위치이동)** 을 고릅니다.  
이미 로그가 붙은 글을 수정할 때는 다시 이동하지 않습니다.

- 목적지는 **현재 위치에서 통행으로 연결된 맵**만 나옵니다. 「현재위치 유지」도 고를 수 있습니다.
- 아직 위치가 없으면(관리자가 안 넣었을 때) 사용 중인 맵을 전부 고를 수 있습니다.
- 탐색 횟수가 없으면 글을 올릴 수 없습니다. (설정에서 제한을 둔 경우)
- 글이 올라가면 본문에 이동·이벤트 로그가 붙고, 캐릭터 위치가 갱신됩니다.

목록 위에 전체 맵 이미지를 넣해 두었다면, 지역을 한눈에 볼 수 있습니다.

### 몬스터 공략 (댓글 / 타임라인 답글)

이동 이벤트로 **몬스터**가 나온 글에는 HP가 보입니다.  
**같은 맵에 있는** 캐릭터로 그 글에 댓글(타임라인이면 인라인 답글)을 달 때 **몬스터 공략**이 나옵니다.

- 공격력은 주사위 2개(1~6) + (선택) 인벤의 **공격력추가** 아이템입니다. 쓰면 소모됩니다.
- 유저 공격이 몬스터 공격보다 크면 몬스터 HP가 깎입니다.
- HP가 0이 되면 처치로 끝납니다. 그 뒤에는 공략 옵션이 사라집니다.

플레이어 캐릭터 HP는 이 모듈에서 깎지 않습니다.

## 다른 모듈과 함께 쓸 때

점령전(`bbs_action_k_dom`)과 같이 켜도 됩니다. 글쓰기 액션에서 **지역 탐색**과 **점령전**이 따로 나옵니다. 한 글에는 액션이 하나만 기록됩니다.  
위치·횟수 저장소도 서로 다릅니다.

---

## 화면 커스텀

플레이어가 보는 화면의 마크업·스타일을 바꿀 때 엽니다. 경로는 모두 `module/bbs_action_map/` 기준입니다.  
글쓰기 패널·목록 맵은 `lib.php` / `bootstrap.php` 훅에서 그립니다. 관리자(`admin/`)는 보통 손대지 않습니다.

| 화면 | PHP (마크업) | CSS |
|------|--------------|-----|
| 목록 맵 오버뷰 | `list_top` 훅 → `lib.php` 렌더 | `css/map.css` |
| 글쓰기·이동 패널 | 훅 패널 (`lib.php`) | `css/map.css` (+ `js/map.js`) |
| 이동 로그 | `views/log_MAP.php` | `css/map.css` |
| 몬스터 공략 로그 | `views/log_MAP_MON.php` | `css/map.css` |

## 자주 막히는 지점

- 글쓰기에 지역 탐색이 없다 → 그 게시판에서 모듈 글(write)이 꺼져 있거나, 이미 로그가 있는 수정 글입니다.
- 「이동할 수 없다」 → 맵 **통행**에 목적지가 없거나, 맵 **사용**이 꺼져 있습니다.
- 횟수가 없다고 나온다 → 탐색 설정의 분기 한도를 다 썼습니다. 다음 분기까지 기다리거나 관리자가 설정을 바꿉니다.
- 목록 위 지도가 없다 → 탐색 설정에 **맵 이미지**를 넣지 않았습니다.
- 이벤트가 안 나온다 → 사용 체크, 확률 구간, 획득가능갯수(한도)를 확인합니다.
- 몬스터 공략이 없다 → 원글에 몬스터가 없거나 이미 처치됐거나, **캐릭터 위치가 그 글의 맵과 다릅니다**.
- 공격력추가 아이템을 못 쓴다 → 아이템 타입이 `공격력추가`이고, **지금 쓰는 캐릭터** 인벤에 있어야 합니다.
