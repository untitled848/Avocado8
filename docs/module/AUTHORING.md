# 모듈 사용 · 제작 (운영자 / 테마 제작자)

코어 파일을 고치지 않고 기능을 켜고 끌 수 있는 **훅 기반 확장**입니다.  
사이트 관리자와 테마를 고치는 사람을 위한 문서입니다.

관리자 화면(목록·켜기·업로드·점검): [000 · 모듈 관리](../adm/000-module.md)  
모듈을 **코드로 새로 만들거나 이식**하려면 [AGENTS.md](AGENTS.md) 를 봅니다.

각 모듈의 화면 설명은 `module/<이름>/README.md` 입니다. 관리자 → 모듈 → 해당 모듈의 도움말에서 열립니다.  
마크업·CSS를 고칠 위치는 각 README의 **화면 커스텀** 절에 표로 정리되어 있습니다.

이 문서의 본보기는 **기본 제공 모듈**만 씁니다. 폴더명과 관리자 `?m=` 은 아래와 같습니다.

| 부르는 이름 | 폴더 (`?m=`) | 하는 일 |
|-------------|--------------|---------|
| 액션 (`bbs_action`) | `bbs_action_search` | 탐색(S). `it_type=탐색횟수` |
| 조합 (`bbs_combine`) | `bbs_action_combine` | 조합(H). `it_type=조합횟수` |
| 주사위 | `bbs_dice` | `wr_dice` 체크. action 값 없음 |
| 아이템 사용 | `bbs_item_use` | 글/댓글에서 아이템 사용·선물 게이트 |

네 모듈은 설치 시 켜지며 **데이터 제거·폴더 삭제가 없습니다.**  
학습용 **액션 샘플**(`bbs_action_sample`)은 기본 제공이 아닙니다. 켜고 지울 수 있고, 새 액션을 만들 때 폴더를 복사하는 템플릿입니다. 설명은 [§7](#7-액션-샘플-학습용) 과 [`bbs_action_sample/README.md`](../../module/bbs_action_sample/README.md).  
`module/` 에 다른 폴더가 있으면 선택 패키지입니다. 켜기 절차는 같고, 화면·위젯·아이템 종류는 **그 모듈 README** 를 봅니다.

## 1. 무엇을 켜는가

모듈은 `module/<이름>/` 한 폴더입니다. 켠 모듈만 매 요청에 로드됩니다.

기본 제공 네 모듈은 모두 **게시판 스코프**입니다. 전역으로 켠 뒤 **게시판/타임라인마다** 글쓰기·댓글을 다시 on/off 합니다. 기본값은 보드에서 꺼짐(`board_default=off`)입니다.

같은 종류는 한 개만 활성입니다 (`module_type`): 탐색(`search`), 조합(`combine`), 주사위(`dice`), 글 아이템(`item_bbs`).

상태 파일:

- `data/module/state.json` — 어떤 모듈이 켜져 있는지
- `data/module/board_state.json` — 게시판·타임라인별 on/off (기본값과 다를 때만 저장)

관리 화면:

| 화면 | 주소 |
|------|------|
| 모듈 목록 (켜기/끄기/재설치/업로드) | `/adm_module/module_list.php` |
| 모듈 설정 (사이드바 메뉴) | `/adm_module/module.php?m=<이름>&p=…` |
| 훅 점검 | 모듈 목록의 [점검] |
| 훅 인덱스 (소스에서 추출) | `/adm_module/hook_registry.php` |
| 게시판별 모듈 | 게시판 수정 폼의 **모듈** 섹션 |

## 2. 켜기 · 끄기 · 재설치 · 업로드

1. **켜기** — 목록에서 활성화. `install.php` 가 있으면 **처음 켤 때** 한 번 실행됩니다 (테이블·컬럼·기본 설정).
2. **끄기** — 다음 요청부터 훅이 안 붙습니다. 데이터·테이블은 남습니다.
3. **재설치** — 이미 켠 모듈에 컬럼을 추가한 뒤에 씁니다. `install.php` 를 다시 돌리고 **데이터는 유지**합니다. 끄고 켜기와는 다릅니다.
4. **제거** — `uninstall.php` 후 목록에서 뺍니다. 폴더는 직접 지웁니다. 기본 제공 모듈은 이 버튼이 없습니다.
5. **업로드** — 슈퍼 관리자만 `.tar.gz`. 최상위 폴더에 `module.php` 가 있어야 합니다. 같은 이름이면 파일만 덮고 DB는 유지합니다. 켠 모듈의 버전이 올라가면 `upgrade.php`(없으면 `install.php`)가 돕니다.

```powershell
cd module
tar -czf bbs_xxx.tar.gz bbs_xxx
```

`depends` 가 있는 모듈은 선행 모듈을 먼저 켭니다.

## 3. 게시판과 타임라인

탐색·조합·주사위·아이템 사용은 **게시판 스킨(mmb/basic 등)** 과 **타임라인 컴포저** 둘 다에 붙을 수 있습니다.

- 모듈을 전역으로 켠 것만으로는 폼이 안 나올 수 있습니다. `board_default=off` 인 모듈은 **그 게시판/타임라인 수정 화면에서 글쓰기(필요하면 댓글)를 체크**해야 합니다.
- 체크박스가 회색(disabled)이면 그 스킨이 모듈이 필요로 하는 훅을 안 쏩니다. 스킨을 바꾸거나, mmb+타임라인을 같이 쓰는 모듈이면 **공통 훅만** 요구하도록 만든 모듈인지 봅니다.
- 기본 제공 네 모듈은 **글쓰기와 댓글을 따로** 켭니다. 글에만 탐색을 쓰고 댓글에는 안 쓰려면 댓글 체크만 끕니다.

| | 게시판 (mmb 등) | 타임라인 |
|--|-----------------|----------|
| 글 저장 | `write.php` | AJAX JSON (`ajax_post.php`) |
| 작성 UI | 라벨 + 셀렉트 | 아이콘 토글 + 패널 |
| 스타일 | 게시판 `_head` | 목록·프로필도 `timeline_print_css_head()` |
| 아이템 사용/선물 | 원글은 사용+선물, mmb 댓글은 **사용만** | 원글·댓글 모두 사용+선물 (`게시판 아이템 사용` 모듈) |

액션을 끈 보드에도 **이미 저장된 로그 HTML** 은 남는 것이 정상입니다. 모듈을 목록에서 끄면(전역 OFF) 로그 렌더도 사라집니다.

## 4. 테마에 위젯 심기

테마/스킨에서 모듈 함수를 직접 부르지 않습니다. **코드를 넣고 싶은 위치**에 아래 한 줄을 붙여 넣습니다.

```php
<?php echo get_widget('모듈명'); ?>
<?php echo get_widget('모듈명', '위젯키', $ch); ?>
<?php echo get_widget('모듈명', 'default', $ch, 160); ?>
```

관리자 모듈 목록에서 **위젯** 태그가 붙은 모듈만 이 함수를 쓸 수 있습니다.  
**기본 제공 네 모듈에는 위젯이 없습니다.** 키·역할은 **그 모듈 README** 를 따릅니다.

| 모듈 | 폴더 | 위젯 |
|------|------|------|
| 퀘스트 | `k_quest` | 수행 중 목록 (`default`) — [README](../../module/k_quest/README.md) |
| 펫 | `k_pet` | 펫 상태창 (`default`) — [README](../../module/k_pet/README.md) |
| 포켓몬 | `k_pokemon` | `entry` / `partner` / `relation` — [README](../../module/k_pokemon/README.md) |
| 종합 전투 | `k_battle` | `default` / `skill` / `equip` / `skill_list` / `equip_list` — [README](../../module/k_battle/README.md) |
| 미니룸 | `k_spacemaker` | `default` 또는 방 종류 ID — [README](../../module/k_spacemaker/README.md) |

- 모듈이 꺼져 있으면 **빈 문자열**입니다. fatal 이 나면 안 됩니다.
- 세 번째 인자는 캐릭터 행입니다. 생략하면 페이지의 `$ch`, 없으면 `$character`. **멤버 목록처럼 루프 안 `$ch`** 는 반드시 넘깁니다. 안 넘기면 모든 칸에 같은 캐릭터가 나옵니다.
- 네 번째는 선택(크기 등).

공개 멤버 보기에서 모듈이 안 보이면, 테마가 `viewer.skin.php` 를 덮으면서 `$viewer_info` / `$viewer_bag` / `$viewer_relation` / `$viewer_extra_tabs` / `$viewer_tools` 를 안 그렸을 수 있습니다.

색은 사이트 디자인 변수(`--d-color_point` 등)를 따릅니다. 위젯만 다른 색이면 그 모듈 CSS 문제입니다.

## 5. 아이템 사용

아이템 **종류(`it_type`)** 는 모듈이 관리자 아이템 폼에 옵션으로 넣습니다. 모듈을 켜야 그 종류가 나타나고, 사용 효과가 동작합니다.

### 사용 입구

| 입구 | 어디서 | 조건 |
|------|--------|------|
| **인벤 사용** | 마이페이지 인벤 → [사용] | 그 효과를 제공하는 모듈이 **켜져** 있으면 됨 |
| **자비 사용** | 글/댓글 작성 폼의 아이템 칸 | 위 + 그 보드에서 **게시판 아이템 사용** (`bbs_item_use`) 이 ON |

`게시판 아이템 사용` 은 기본이 꺼짐입니다. 게시판/타임라인 수정 화면의 모듈 섹션에서 글쓰기(필요하면 댓글)를 켭니다.

| | 사용 | 선물 |
|--|------|------|
| mmb 원글 | O | O |
| mmb 댓글 | O | 불가 (서버도 거절) |
| 타임라인 원글·댓글 | O | O |

### 종류 목록 (모듈을 켠 뒤)

| 종류 (`it_type`) | 효과 | 입구 | 모듈 |
|------------------|------|------|------|
| 프로필수정 | 캐릭터 프로필 폼으로 이동 | 인벤 | (코어) |
| 아이템추가 | 다른 아이템을 넣는 폼 | 인벤 | (코어) |
| 스탯회복 | 지정 스탯 회복 | 인벤 | (코어) |
| 뽑기 | 확률표에서 다른 아이템 | 인벤 / 자비 | (코어) |
| 탐색횟수 | 남은 탐색 ±N | 인벤 / 자비 | `bbs_action_search` |
| 조합횟수 | 조합 횟수 | 인벤 / 자비 | `bbs_action_combine` |
| 샘플횟수 | 샘플 액션 횟수 | 인벤 / 자비 | `bbs_action_sample` (학습용. 기본 제공 아님) |

그 외 이름은 해당 모듈을 켠 뒤에만 셀렉트에 나옵니다. `it_value` 의미는 종류마다 다릅니다 (횟수, 회복량, 뽑기 그룹 등).

### 운영 순서

1. 효과 모듈을 켭니다 (예: 탐색 액션).
2. 글에서 쓰려면 해당 게시판/타임라인에서 `게시판 아이템 사용` 을 켭니다 (기본은 꺼짐).
3. 아이템 등록에서 **종류**를 위 표의 이름 그대로 고릅니다. 수치·영구 사용(`it_use_ever`)을 정합니다.
4. 캐릭터에게 지급합니다.

종류별 화면 설명은 각 모듈 `README.md` 와 아이템 관리 화면을 봅니다. 새 종류를 **코드로** 추가하려면 [AGENTS.md §7](AGENTS.md#7-아이템-기능--두-입구).

### 자주 묻는 질문

**글 폼에 아이템 칸이 없어요**  
그 보드에서 `게시판 아이템 사용` 이 꺼져 있거나, 글쓰기 스코프만 꺼져 있습니다. 수정 모드에서 이미 사용한 글은 칸을 숨기는 것이 정상입니다.

**인벤에서는 되는데 글에서는 효과가 없어요**  
자비사용은 `bbs_item_use` 게이트가 필요합니다. 효과 모듈만 켜진 상태일 수 있습니다.

**모듈을 끄면 가진 아이템은?**  
인벤에는 남습니다. 사용해도 그 종류 효과가 적용되지 않습니다. 다시 켜면 동작합니다.

**영구 사용을 켰는데 안 사라져요**  
`it_use_ever` 가 그 목적입니다. 일회성이면 체크를 끕니다.

**mmb 댓글에서 선물이 안 돼요**  
설계입니다. 타임라인 댓글에서는 됩니다.

**종류 셀렉트에 이름이 없다**  
해당 모듈이 켜져 있는지, 아이템 폼을 새로고침했는지 확인합니다.

## 7. 액션 샘플 (학습용)

폴더 `bbs_action_sample`, 관리자 표시명 **액션 샘플**. 삭제·끄기가 됩니다. 실서비스 기능이 아니라 **액션 모듈을 복제할 때 쓰는 템플릿**입니다.

켜는 방법: 모듈 목록에서 활성화 → 그 게시판/타임라인에서 글쓰기·댓글 체크. 설정은 `/adm_module/module.php?m=bbs_action_sample&p=setting`.

글쓰기·댓글에 세 가지 예시가 같이 나옵니다.

| 옵션 | `action` | 언제 |
|------|----------|------|
| 샘플공통 | `SAMPLE` | 글·댓글. 일일 횟수 `character_sample` 를 씀 |
| 샘플쓰기전용 | `SAMPLE_W` | 글만 |
| 샘플코멘트전용 | `SAMPLE_C` | 원글이 `SAMPLE_W` 일 때만 댓글에 보임 |

목록 상단에 배너가 붙습니다. 보드에서 모듈만 꺼도 **이미 저장된 로그 HTML·로그 CSS** 는 남습니다. 모듈 목록에서 끄면(전역 OFF) 그때는 로그 스타일도 없습니다.

아이템 종류 **샘플횟수** 가 생깁니다. 글에서 쓰려면 그 보드에서 `게시판 아이템 사용` 도 켭니다.

상세·복제 순서: [`bbs_action_sample/README.md`](../../module/bbs_action_sample/README.md). 제작 규칙은 [AGENTS.md §12](AGENTS.md).

## 8. 모듈 UI 테마 · 사이트 테마

사이트 화면 테마는 `theme/이름/` + 테마 프리셋 슬롯입니다. 안내는 [테마 만들기](../theme/AUTHORING.md).

일부 모듈(예: ORPG)은 **모듈 자체 UI** 만 `module/<mod>/theme/<theme>/` 아래에 둡니다. 이것은 사이트 테마 프리셋과 무관합니다.  
사이트 쪽 `mtheme:` / `mtheme/…` 스킨 값 모델은 쓰지 않습니다.

## 9. 문제 해결

| 증상 | 먼저 볼 것 |
|------|------------|
| 목록에 모듈이 없다 | 폴더명과 `module.php` 의 `name` 이 같은지 |
| 켰는데 글쓰기 옵션이 없다 | 그 게시판/타임라인에서 모듈 체크. `board_default=off` |
| 체크박스가 비활성 | 스킨이 필요한 훅을 안 쏨. mmb 전용 훅을 타임라인에 요구한 모듈일 수 있음 |
| 폼은 있는데 저장이 안 됨 | 댓글 쪽 옵션을 안 넣었거나, 타임라인이면 네트워크에 POST 키가 실리는지 |
| 타임라인만 “응답 형식이 올바르지 않습니다” | 모듈이 `alert()` HTML 을 냄. JSON 만 허용 |
| 아이템을 글에서 골라도 효과가 없다 | `게시판 아이템 사용` 이 그 보드에서 ON 인지. 효과 모듈도 켜져 있는지 |
| 새 컬럼이 DB에 없다 | 이미 켠 모듈은 **재설치**. 끄고 켜기만으로는 `install.php` 가 다시 안 돈다 |
| 위젯이 모든 멤버에 같음 | `get_widget(..., $ch)` 에 루프 행을 안 넘김 |
| 모듈 OFF 인데 테마에서 fatal | `get_widget()` 대신 모듈 PHP 를 include 함 |

훅이 사이트에 실제로 있는지는 관리자 **훅 인덱스**를 재스캔해 확인합니다.
