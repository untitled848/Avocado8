# 200 · 회원 관리

**메뉴 위치:** 관리자 → 회원 관리

계정 가입 규칙, 회원 목록, 게시판 활동량(로그/댓글)을 다룹니다. **가입 허용 자체**는 [통합 권한관리](100-community.md#통합-권한관리) 입니다. 이 메뉴는 가입 **양식과 정책**, 이미 가입한 사람 관리입니다.

---

## 회원가입 설정

**경로:** `/adm/member_register_form.php`  
**메뉴:** 회원 관리 → 회원가입 설정

맨 아래 **저장** 을 눌러야 반영됩니다.

### 가입 기본


| 항목          | 하는 일                                              |
| ----------- | ------------------------------------------------- |
| 가입 시 권한     | 새로 가입한 사람의 등급. 보통 **일반멤버**.                       |
| 가입 시 지급 포인트 | 가입 직후 주는 포인트(화폐가 아닐 수 있음). 0 이면 없음.               |
| 탈퇴 후 자동 삭제일 | 탈퇴 신청 후 N일이 지나면 자료를 지웁니다. **0이면 이 자동 삭제는 안 합니다.** |


가입을 막을지는 권한관리의 **계정 생성 허용** 입니다.

### 닉네임 정책

- 최소·최대 글자수
- 사용 가능 문자: 제한 없음 / 한글만 / 한글+영문만
- **아이디·닉네임 금지단어**: 쉼표로 구분. `admin`, `관리자` 등이 기본으로 들어 있습니다.



### 생년 입력 방식


| 선택      | 하는 일                   |
| ------- | ---------------------- |
| 직접입력    | 가입 폼에 연도 칸 (예: 00)     |
| 체크박스    | “연령 제한에 저촉되지 않습니다” 동의만 |
| 입력받지 않음 | 생년 칸 없음                |




### 추가 입력 항목 / 도움말

가입 폼에 **커스텀 칸**을 붙입니다. **＋ 항목 추가** 후:


| 칸   | 하는 일             |
| --- | ---------------- |
| 코드  | 영문·숫자·`_` (저장 키) |
| 라벨  | 화면에 보이는 이름       |
| 유형  | 한 줄 / 여러 줄 / 선택  |
| 옵션  | 선택형일 때 `옵션1      |
| 필수  | 비우면 가입이 안 됩니다    |


**항목별 도움말**은 아이디·비밀번호·닉네임·생년·추가 칸 아래에 나오는 안내입니다. 비우면 안내가 안 나옵니다.

### 약관 / 안내문

- **커뮤니티 활동 규칙**
- **캐릭터 생성 유의사항**

가입 시 오너 동의로 보여 줍니다.

## 회원 관리

**경로:** `/adm/member_list.php`  
**메뉴:** 회원 관리 → 회원 관리

총 인원, **차단**, **탈퇴** 수가 위에 있습니다. 링크를 누르면 그 상태 순으로 정렬됩니다.

검색: 아이디, 닉네임, 권한, 이메일, IP, 추천인.

목록: 아이디, 이름, 생년, 보유 캐릭터(이름 클릭 → 캐릭터 수정), 상태, 권한, 가입일, 최종접속, **수정**.

권한은 목록에서 바로 바꿀 수 있습니다. 방문자 / 일반멤버 / 운영자.

### 일괄 버튼

체크한 뒤:


| 버튼   | 하는 일                                                      |
| ---- | --------------------------------------------------------- |
| 선택수정 | 목록에서 바꾼 권한 등을 저장                                          |
| 선택탈퇴 | 탈퇴 처리                                                     |
| 완전삭제 | 회원 자료를 지움. **아이디·이름·닉네임은 남겨 두어 다른 사람이 같은 아이디를 못 쓰게 합니다.** |


**회원추가**: `/adm/member_form.php` 에서 아이디·비밀번호·이름 등을 직접 만듭니다. 수정 화면에서도 비밀번호를 바꿀 수 있습니다. 본인보다 권한이 같거나 높은 회원은 수정할 수 없습니다.

## 활동량 관리

**경로:** `/adm/action_list.php`  
**메뉴:** 회원 관리 → 활동량 관리

지정한 **게시판**과 **기간** 동안 글(로그)·댓글 수를 봅니다. 기본 기간은 이번 주 월요일~다음 일요일입니다.

- 최고관리자·탈퇴·캐릭터 없는 계정은 목록에서 빠집니다.
- **누적경고** 횟수와 **경고내용**을 칸에 넣고 저장할 수 있습니다.
- 대표 캐릭터 이름은 캐릭터 수정 화면으로 연결됩니다.

출석·활동 보상 정산은 [통합 정산](520-calc.md) 을 씁니다. 여기는 집계·경고용입니다.

---



## 자주 하는 일

1. **오픈 전 가입 폼 다듬기** → 회원가입 설정에서 닉네임 길이·금지단어·약관 → 저장. 가입 on/off는 권한관리.
2. **운영자 계정 만들기** → 회원추가 또는 가입 후 목록에서 권한을 운영자로.
3. **문제 회원** → 목록에서 체크 후 선택탈퇴. 아이디 재사용을 막으려면 완전삭제 대신 탈퇴를 권합니다.
