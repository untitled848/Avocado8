# 400 · 캐릭터/프로필

**메뉴 위치:** 관리자 → 캐릭터/프로필

캐릭터 **양식**(어떤 칸을 받을지), **캐릭터 목록·승인**, 진영·직업(이름은 [커뮤니티 설정](100-community.md) 에서 바꿈), **리셋 카운터**를 다룹니다. 한 아이디가 캐릭터를 몇 개까지 만드는지는 [통합 권한관리](100-community.md#통합-권한관리) 입니다.

---

## 프로필 양식 관리

**경로:** `/adm/character_article_list.php`  
**메뉴:** 캐릭터/프로필 → 프로필 양식 관리

캐릭터 신청·프로필에 어떤 칸이 나올지 정합니다. **섹션마다 확인이 따로** 있습니다. 다른 섹션의 확인을 누르면 지금 적던 내용이 날아갈 수 있습니다. **프로필 항목 등록** 은 그 섹션 맨 아래 확인만 누릅니다.

| 섹션 | 하는 일 |
|------|---------|
| 멤버 리스트 표시 | `/member` 두상 크기(px), 그리드(자동 채움/맞춤/갯수 고정), 정렬(등록순·이름·랭킹). NPC는 멤버와 **분리/통합**, 위치(위·아래) |
| 기본 프로필 양식 | 프로필에 타이틀·옷장·인벤·금액·경험치·랭킹·스탯을 켤지. 두상·흉상·전신 이름, 사용, 외부 URL 허용, 필수. 이름 글자 수 |
| 추가 프로필 양식 | 이미 만든 칸. ⋮⋮ 드래그로 순서, 카드에서 삭제 후 확인. 시기 체크는 카드 머리에서 |
| 프로필 항목 등록 | 새 칸. 고유코드(영문·_), 타입(한줄/여러줄/선택/이미지/외부링크), 공개(전체/오너+관리자/관리자만) |

진영·직업 칸은 명칭이 비어 있으면 프로필에 안 나옵니다. 명칭은 아래에서 넣거나 커뮤니티 설정과 맞춰 둡니다.

## 캐릭터 관리

**경로:** `/adm/character_list.php`  
**메뉴:** 캐릭터/프로필 → 캐릭터 관리

탭: **전체 / 메인 / 서브 / NPC**. 위쪽에 승인대기·수정중·삭제 수가 있고, 누르면 그 상태만 봅니다.

검색: 캐릭터 이름, 오너 아이디, 승인현황. **캐릭터추가** 로 관리자가 직접 만듭니다.

목록에서 유형(MAIN/SUB/NPC)과 상태(수정중/대기/승인/삭제)를 바꾸고 **선택수정** 합니다.

| 버튼 | 하는 일 |
|------|---------|
| 선택승인 | 상태를 승인으로 |
| 선택삭제 | 상태만 ‘삭제’. **나중에 복구 가능** |
| 선택제거 | 캐릭터와 아이템·포인트 등 **관련 정보까지 지움. 복구 불가** |

줄의 **수정** 은 상세 화면, **제거** 는 그 한 명 완전 삭제입니다.

캐릭터 생성 허용은 권한관리입니다. 양식은 위 프로필 양식입니다.

## 진영 관리 / 직업 관리

**경로:** `/adm/side_list.php`, `/adm/class_list.php`  
**메뉴 이름:** 분류명에 넣은 이름 (기본: 진영, 직업)

한 화면에 탭이 있습니다.

| 탭 | 하는 일 |
|----|---------|
| 분류명 설정 | 메뉴·폼에 찍히는 이름. 비우면 미사용. **이름 저장** |
| 목록 | 이미 만든 항목. 선택수정·선택삭제 |
| 등록 | 이름, 이미지, **선택권한**(일반멤버/운영자). **확인** |
| 시기별 활성 설정 | 시기마다 어떤 항목을 켤지. 리뉴얼/AU 시기만 나옴 |

캐릭터 신청 폼의 선택지가 여기서 나옵니다. 시기에 체크가 하나도 없으면 폴백(직전 리뉴얼 또는 빈 값)이 적용됩니다.

## 리셋 카운터 관리

**경로:** `/adm/reset_list.php`  
**메뉴:** 캐릭터/프로필 → 리셋 카운터 관리

출석·일일 횟수처럼 **주기적으로 0으로 돌아가는 숫자**입니다. 모듈이 등록한 항목은 이 목록에서 **읽기 전용**입니다.

탭:

| 탭 | 하는 일 |
|----|---------|
| 카운터 일람 | 이름, 유형(관리자/회원/캐릭터), 주기(매시·매일·매주 등), 기본값·최소·최대, 다음 리셋 시각 |
| 값 관리 | 실제 숫자(`rm_value`)만 고침 |

주기를 바꾸려면 해당 모듈 설정 쪽을 봐야 합니다. 여기서는 값 확인·수동 수정이 목적입니다.

1. **신청 받기** → 프로필 양식 확인 → 권한관리에서 캐릭터 생성 허용 → 캐릭터 관리에서 승인대기 승인  
2. **시즌 진영 바꾸기** → 진영 관리에서 시기별 사용 체크
