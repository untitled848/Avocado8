# 000 · 모듈 관리

**메뉴 위치:** 관리자 왼쪽 맨 위 `←모듈 관리로`  
**실제 화면:** `/adm_module/` (코어 `/adm/` 과 별도)

사이트에 붙는 **기능 모듈**을 켜고 끄고, 설치·점검하는 곳입니다. 코어 관리자 메뉴(커뮤니티, 게시판, 캐릭터 등)와 화면이 나뉩니다.

기본 제공(삭제 불가): 탐색(`bbs_action_search`), 조합(`bbs_action_combine`), 주사위(`bbs_dice`), 게시판 아이템 사용(`bbs_item_use`). 그 외 `module/` 폴더는 선택 패키지입니다.

- 코어 관리자에서 들어오면 사이드바 제목이 `←모듈 관리로` 입니다.
- 모듈 관리 안에서는 `←관리자 페이지로` 로 다시 `/adm/` 으로 돌아갑니다.

이 설명서는 **모듈 목록 / 훅 인덱스 / 모듈 점검** 만 다룹니다. 각 모듈의 설정 화면은 해당 모듈을 켠 뒤 왼쪽 메뉴에서 들어갑니다.

모듈을 쓰거나 테마에 위젯을 심을 때: [모듈 사용 · 제작 (운영자)](../module/AUTHORING.md)  
모듈을 코드로 만들거나 고칠 때: [모듈 제작 가이드 (에이전트)](../module/AGENTS.md)

## 모듈 목록

**경로:** `/adm_module/module_list.php`  
**메뉴:** 모듈 → 모듈 목록

등록된 모듈 카드가 카테고리별로 나옵니다.

화면 위쪽에는 **등록된 모듈 수 · 켜진 모듈 수** 가 표시됩니다. 검색·필터를 쓰면 **표시 N개** 도 같이 나옵니다. 오른쪽 **모듈 점검** 은 켜 둔 모듈 전체를 한 번에 검사합니다.

### 카테고리


| 구분     | 의미                                       |
| ------ | ---------------------------------------- |
| 일반 모듈  | 사이트 전체에 붙는 기능                            |
| 게시판 모듈 | 게시판마다 켜고 끌 수 있는 기능 (조합, 탐색, 주사위, 아이템 사용 등) |
| 독립 모듈  | 다른 코드에 끼어들지 않고 자기 페이지·테이블만 쓰는 모듈. 훅 점검 대상이 아님 |


### 검색·필터

- 검색창: 이름, 설명, 모듈 id (`bbs_action_search` 등), 작성자. 위젯이 있는 모듈은 `위젯` / `widget` 로도 찾을 수 있습니다.
- 전체 / 켜짐 / 꺼짐 — 해당 상태의 카드만 남깁니다. 결과가 없는 카테고리 제목은 숨겨집니다.

## 새 모듈 설치

모듈은 `module/<이름>/` 폴더 하나입니다. 목록에 보이게 하려면 그 폴더에 `module.php`(메타)가 있어야 합니다. **업로드만으로 자동 켜지지 않습니다.** 목록에 나타난 뒤 **켜기** 를 눌러야 기능이 살아납니다.

설치 방법은 두 가지입니다.

### 1. 화면에서 tar.gz 업로드 (권장)

모듈 목록 위 **새 모듈 설치 (tar.gz 업로드)** 영역입니다. **최고관리자**만 보입니다.

1. `.tar.gz` 파일을 고른 뒤 **설치** 를 누릅니다. (`.zip` 은 안 됩니다.)
2. 서버가 압축을 검사한 뒤 `module/` 아래에 풉니다.
3. 성공하면 목록으로 돌아가며 「업로드 완료 — 활성화하려면 [켜기]」 안내가 뜹니다.
4. 해당 카드에서 **켜기** 를 누릅니다. 처음 켤 때 `install.php` 가 있으면 한 번 실행되어 테이블·컬럼·기본 설정을 만듭니다.

#### 패키지 형식

압축 안 구조는 대략 다음과 같아야 합니다.

```text
모듈이름.tar.gz
 └─ 모듈이름/          ← 최상위 폴더는 하나만
     ├─ module.php     ← 필수
     ├─ install.php    ← (선택) 처음 켤 때·재설치 시
     ├─ uninstall.php  ← (선택) 데이터 제거 시
     ├─ README.md      ← (선택) 도움말 버튼
     └─ …
```

| 규칙 | 설명 |
|------|------|
| 최상위 폴더 1개 | 여러 폴더가 섞여 있으면 거부됩니다. |
| `module.php` | 그 폴더 바로 아래에 있어야 합니다. |
| 폴더 이름 | 영문으로 시작, 영문·숫자·`_` 만. `_` 로 시작하면 코어 예약이라 불가. |
| 확장자 | 파일명 끝이 `.tar.gz` 이어야 합니다. |

패키지를 직접 만들 때 예:

```powershell
cd module
tar -czf bbs_xxx.tar.gz bbs_xxx
```

#### 같은 이름이 이미 있을 때 (덮어쓰기)

이미 `module/이름/` 이 있으면 바로 덮지 않고 **덮어쓰기 확인** 화면이 납니다.

- **파일만** 패키지 내용으로 바꿉니다. DB 테이블·저장된 데이터는 지우지 않습니다.
- 현재 버전 / 패키지 버전 / 켜짐·꺼짐 상태가 표시됩니다.
- **켜진** 모듈이고 패키지 버전이 더 높으면, 덮어쓴 뒤 `upgrade.php`(없으면 `install.php`)로 스키마를 보강합니다.
- **꺼진** 모듈은 파일만 교체합니다. 나중에 **켜기** 할 때 버전에 따라 upgrade가 돕니다.
- 기본 제공 모듈도 덮어쓸 수 있지만, 코어 파일이 바뀌므로 확인 문구를 읽으세요.
- **취소** 하면 업로드를 버리고 목록으로 돌아갑니다. 확인 대기는 약 1시간입니다.

### 2. 폴더를 직접 넣기 (FTP·배포)

서버의 `module/` 아래에 모듈 폴더를 그대로 복사해도 됩니다. 형식은 업로드와 같습니다 (`module.php` 필수).

1. `module/새모듈이름/` 을 올립니다.
2. 모듈 목록을 새로고침하면 카드가 생깁니다.
3. **켜기** 로 활성화합니다.

이미 있는 모듈을 파일만 교체한 경우에도, 켠 상태에서 버전이 올랐다면 다음 요청·재설치·덮어쓰기 마무리 과정에서 스키마 보강이 이뤄질 수 있습니다. 컬럼이 빠졌다면 카드의 **재설치** 가 가장 확실합니다.

### 설치 후 체크리스트

1. 목록에서 카드가 보이거나, 검색으로 id를 찾습니다.
2. **켜기** — 단독 그룹이면 확인 창이 뜹니다.
3. `↳ 필요: …` 태그가 있으면 **선행 모듈을 먼저** 켭니다.
4. **설정** / 왼쪽 새 메뉴로 들어가 필요한 값을 넣습니다.
5. `📋 게시판별 켜고 끄기 가능` 이면 [게시판 수정](300-board.md) 또는 타임라인 설정의 **모듈** 칸에서 글쓰기(필요하면 댓글)를 따로 켭니다.
6. 테마에 넣을 **위젯** 이 있으면 해당 모듈 **도움말** 의 키를 보고 `get_widget(...)` 한 줄을 붙입니다.

## 모듈 카드 구성

카드 한 장이 모듈 하나입니다. 켜진 카드는 초록 계열(`켜짐`), 꺼진 카드는 회색(`꺼짐`)으로 구분됩니다.

### 머리글

| 요소 | 설명 |
|------|------|
| 제목 | 사람이 읽는 모듈 이름 (`module.php` 의 title) |
| `(모듈id)` | 폴더 이름이자 관리자 URL의 `?m=` 값. 검색·의존 표시에 쓰입니다. |
| ● 켜짐 / ○ 꺼짐 | 지금 사이트가 이 모듈을 로드하는지 |

### 설명·버전

| 요소 | 설명 |
|------|------|
| 설명 문단 | 모듈이 무엇을 하는지 짧은 소개. 없으면 비어 있습니다. |
| `v버전` | `module.php` 의 version |
| `by 작성자` | 작성자 필드가 있을 때만 |
| 버전 배너(이미지) | 일부 모듈이 넣는 안내/출처 배너. 클릭하면 외부 링크로 열릴 수 있습니다. |

### 태그

해당할 때만 카드 중간에 붙습니다.

| 태그 | 의미 |
|------|------|
| 📋 게시판별 켜고 끄기 가능 | 전역 **켜기** 만으로는 부족합니다. 각 게시판·타임라인 수정 화면의 **모듈** 섹션에서 글쓰기/댓글을 다시 켜야 합니다. |
| 🔗 단독 그룹: `이름` | 같은 그룹에서는 **한 번에 하나만** 켤 수 있습니다. 다른 모듈을 켜면 이 모듈은 자동으로 꺼집니다. 예: 탐색(`search`), 조합(`combine`), 주사위(`dice`), 글 아이템(`item_bbs`), CDN 등. |
| 위젯 | 테마·스킨에 `<?php echo get_widget('모듈명'); ?>` 한 줄을 넣을 수 있습니다. 키·역할은 **도움말** 을 봅니다. |
| 글쓰기 / 댓글쓰기 / … | 게시판에서 나뉘는 **스코프**(적용 구간). 기본 제공 네 모듈은 글쓰기와 댓글쓰기를 따로 켭니다. |
| ↳ 필요: `다른모듈id` | 이 모듈을 쓰려면 나열된 모듈을 **먼저** 켜 두어야 합니다. |
| ⚙ 어드민 메뉴 N개 | 켠 뒤 모듈 관리 왼쪽 사이드바에 메뉴 그룹이 N개 생깁니다. |

### 카드 버튼


| 버튼     | 언제 보이나              | 하는 일                                                                                                   |
| ------ | ------------------- | ------------------------------------------------------------------------------------------------------ |
| 켜기     | 꺼진 모듈               | 기능을 활성으로 바꿉니다. 처음이면 `install.php` 실행. 데이터는 그대로입니다. 단독 그룹이면 확인 창이 납니다.                              |
| 끄기     | 켜진 모듈               | 기능을 비활성으로 바꿉니다. 데이터·테이블은 남습니다. 다음 요청부터 훅이 안 붙습니다.                                                     |
| 설정     | 켜진 모듈 + 설정 화면이 있을 때 | 그 모듈 관리 페이지로 갑니다. 단일 설정이면 `module.php?m=…&p=setting`, 메뉴가 여러 개면 그중 첫 메뉴 URL로 갑니다.                  |
| 페이지 보기 | 켜진 모듈 + 사용자 URL이 있을 때 | 모듈이 제공하는 실제 사용자 화면을 새 탭으로 엽니다.                                                                       |
| 재설치    | 켜진 모듈               | `install.php` 를 다시 실행합니다. 빠진 DB 컬럼·기본값을 보강합니다. **기존 데이터는 유지**됩니다. 설치가 중간에 실패했거나 모듈을 고친 뒤 다시 적용할 때 씁니다. |
| 데이터 제거 | 꺼진 모듈 (기본 제공 제외)    | `uninstall.php` 를 실행해 DB·관련 파일을 정리합니다. **되돌릴 수 없습니다.** 폴더는 남습니다.                                     |
| 폴더 삭제  | 꺼진 모듈, 최고관리자만       | 디스크의 `module/이름/` 폴더를 지웁니다. uninstall도 같이 돌아갑니다. **되돌릴 수 없습니다.**                                       |
| 점검     | 항상                  | 아래 [모듈 점검](#모듈-점검) 으로 이 모듈만 검사합니다.                                                                     |
| 도움말    | `README.md` 가 있는 모듈  | 모듈 설명(마크다운)을 새 탭으로 엽니다.                                                                                |


**기본 제공 모듈** (`bbs_action_combine`, `bbs_action_search`, `bbs_dice`, `bbs_item_use`) 은 데이터 제거·폴더 삭제가 없습니다.

켜기 / 끄기 / 재설치 / 데이터 제거 / 폴더 삭제의 차이만 요약하면 다음과 같습니다.

| 동작 | 기능 | DB·데이터 | `module/` 폴더 |
|------|------|-----------|----------------|
| 켜기 | ON | 유지 (처음이면 install로 생성) | 유지 |
| 끄기 | OFF | 유지 | 유지 |
| 재설치 | ON 유지 | 보강만, 삭제 없음 | 유지 |
| 데이터 제거 | OFF | uninstall로 정리 | 유지 |
| 폴더 삭제 | OFF | uninstall 후 정리 | **삭제** |

### 상태 불일치

켜진 것으로 기록돼 있는데 폴더가 없으면 빨간 안내가 뜹니다. **지금 정리하기** 로 활성 목록에서만 뺍니다. (디스크에 없던 항목의 “켜짐” 기록만 지웁니다.)

## 훅 인덱스

**경로:** `/adm_module/hook_registry.php`  
**메뉴:** 모듈 → 훅 인덱스

모듈이 붙는 **연결 지점(훅)** 목록입니다. 소스에서 자동으로 뽑아 온 목록이라, 평소 운영에는 거의 쓸 일이 없습니다. 모듈이 안 붙거나 개발자가 위치를 찾을 때 씁니다.

- **훅명 / 타입(action·filter) / 스코프(general·bbs) / 상태(유효·전체·obsolete)** 로 검색합니다.
- **재스캔**: 소스를 다시 읽어 목록을 갱신합니다. 처음 목록이 비어 있으면 자동으로 한 번 돕니다.
- 각 줄의 **편집**: 훅에 사람용 설명만 적습니다. 코드 스캔 때 이 설명은 덮어쓰지 않습니다.

## 모듈 점검

**경로:** `/adm_module/module_verify.php`  
**메뉴:** 모듈 목록 오른쪽 **모듈 점검**, 또는 카드의 **점검**

켜 둔 모듈이 쓰겠다고 한 훅이, **지금 사이트(현재 테마·스킨)** 에 실제로 있는지 확인합니다.

- 위쪽에 점검 기준 프리셋(테마)이 나옵니다.
- 모듈마다 **정상 / 문제** 와 훅 위치, 그 모듈을 쓰는 게시판이 나옵니다.
- 게시판 훅은 게시판 스킨마다 다를 수 있어, 게시판별로 따로 표시됩니다.
- **독립 모듈** 은 다른 코드에 끼어들지 않으므로 전체 점검에서 빠집니다.

결과가 정상이면 그 모듈은 현재 테마·게시판 스킨과 맞게 붙어 있는 상태입니다. 문제가 나오면 테마/스킨을 바꿨거나, 모듈이 기대하는 연결 지점이 없는 경우입니다.

## 모듈을 켠 뒤

켜진 모듈은 모듈 관리 왼쪽 메뉴에 그룹이 생깁니다. 예: 게시판 액션.

게시판 모듈은 여기서 켠 것만으로 끝나지 않습니다. **각 게시판·타임라인 설정**에서 그 보드에 쓸지 따로 켜야 하는 경우가 많습니다. (`📋 게시판별 켜고 끄기 가능` 태그)  
자세한 위치는 [게시판 관리 · 모듈 구역](300-board.md), [타임라인 관리](301-timeline.md) 를 보세요.

## 주의

- **끄기** 와 **데이터 제거** 는 다릅니다. 끄기는 기능만 멈춥니다. 데이터 제거·폴더 삭제는 복구가 어렵습니다.
- **재설치** 는 데이터를 지우는 작업이 아닙니다.
- **업로드** 는 파일을 넣는 단계입니다. 쓰려면 반드시 **켜기** 가 필요합니다.
- 단독 그룹 모듈을 켜면 같은 그룹의 다른 모듈이 꺼질 수 있습니다. 확인 창을 읽으세요.
- 모듈 설정 화면은 모듈이 **켜져 있어야** 열립니다.
- 기본 제공 네 모듈은 데이터 제거·폴더 삭제가 없습니다.
