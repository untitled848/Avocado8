# 301 · 타임라인 관리

**메뉴 위치:** 관리자 → 타임라인 관리

트위터/마스토돈과 비슷한 **실시간 로그형 타임라인**을 만들고 설정합니다. 사용자 화면은 `/timeline/` 입니다.

타임라인을 이용하려면 **회원가입 → 캐릭터 생성 → 사용자 등록** 을 거쳐야 합니다. 계정만으로는 캐릭터를 만들 수 없고, 캐릭터만으로는 그 타임라인의 **사용자**가 되지 않습니다. 여기서 **사용자** 는 그 타임라인에 등록된 캐릭터입니다.

1. **회원가입** — [회원 관리](200-member.md). 가입 on/off는 [통합 권한관리](100-community.md#통합-권한관리) 입니다.
2. **캐릭터 생성** — [캐릭터/프로필](400-character.md). 승인된 캐릭터만 사용자로 넣을 수 있습니다.
3. **사용자 등록** — 타임라인 목록의 **관리**, 또는 생성·수정의 **사용자 관리**. 아래 [사용자 관리](#사용자-관리) 입니다.

등록된 사용자는 타임라인 **안에서** 캐릭터 프로필과 **별개로** 이름(닉네임), 멘션 아이디, 썸네일, 헤더, 소개, 프로필 주소를 정합니다. 화면은 `/timeline/settings.php` (내 설정). 사이트 멤버 프로필([캐릭터/프로필](400-character.md))과는 데이터가 다릅니다. 타임라인이 여러 개면 **타임라인마다** 따로 둡니다.

---

## 타임라인 목록

**경로:** `/adm/timeline_list.php`  
**메뉴:** 타임라인 관리 → 타임라인 목록

탭: **타임라인 목록** / **스킨 업로드** (`tar.gz`).

생성된 개수가 위에 나옵니다. TABLE·제목으로 검색합니다.

- **타임라인 추가**: 생성 화면으로
- **사이트 DB 점검/보정**: 테이블이 빠졌을 때 [900](900-data.md) 으로

목록에서 제목, 스킨, **열람 권한**(전체/회원/사용자/운영자), **쓰기 권한**(모든 사용자/운영자만), 이미지 수, 최대 글자수, 글쓰기 포인트를 바로 고칩니다. **관리** 숫자는 그 타임라인에 등록된 **사용자**(캐릭터) 수입니다. 숫자를 누르면 사용자 관리로 갑니다. **바로가기** 는 사용자 화면입니다.

- **선택수정**: 목록에서 고친 값 저장
- **선택초기화**: 글·댓글을 비움 (타임라인 자체는 남음)
- **선택삭제**: 타임라인과 글을 지움

## 타임라인 생성·수정

**경로:** `/adm/timeline_form.php`  
**메뉴:** 타임라인 관리 → 타임라인 생성 (수정은 목록에서)


| 구역    | 하는 일                                                                    |
| ----- | ----------------------------------------------------------------------- |
| 기본    | TABLE 이름(영문, 생성 후 변경 불가), 제목, 그룹, 스킨                                    |
| 권한    | 읽기·쓰기 등급. 수정 화면에서 **사용자 관리** 로 캐릭터를 등록합니다.                       |
| 기능    | 이미지 사용·장 수·너비, 본문 최대 글자, DM 사용, 시기(`tl_ti_use`), 새로고침 간격(밀리초), 글·댓글 포인트 |
| 여분필드  | `tl_1` ~ `tl_10` 제목과 값                                                  |
| 스킨 설정 | 그 스킨 전용 옵션                                                              |
| 모듈    | **이 타임라인에서** 켤 기능. 모듈 관리에서 켠 뒤 여기서 다시 켭니다.                              |


확인을 눌러 저장합니다. 생성 시 DB에 글 테이블이 만들어집니다. 스키마가 어긋나면 목록의 **사이트 DB 점검/보정** 을 돌리세요.

## 사용자 관리

**경로:** `/adm/timeline_user.php`  
**메뉴:** 타임라인 목록의 **관리** / 생성·수정의 **사용자 관리**

승인된 캐릭터를 그 타임라인의 **사용자**로 넣거나 뺍니다. 회원가입·캐릭터 생성 다음에 이 등록을 해야 그 타임라인을 이용할 수 있습니다.

등록된 사용자가 있으면 그 캐릭터만 글을 쓸 수 있습니다. 한 명도 없으면 모든 회원이 쓰기 가능합니다. 열람을 **사용자만** 으로 두면 등록된 사용자만 볼 수 있습니다.

검색: 캐릭터명, 회원닉네임, 캐릭터ID. **선택 추가** / **선택 제거**.

### 타임라인 전용 프로필

사용자로 넣을 때 이름은 캐릭터명, 썸네일은 캐릭터 두상으로 채워집니다. 이후 사용자는 타임라인 안 **내 설정**에서 아래를 따로 고칩니다. 캐릭터 프로필을 바꿔도 여기에는 반영되지 않습니다.

| 항목 | 하는 일 |
|------|---------|
| 닉네임 | 글·프로필에 찍히는 이름 |
| 멘션용 아이디 | `@멘션` 검색·매칭 (띄어쓰기 없이 최대 6자) |
| 프로필 썸네일 | 타임라인·멘션 자동완성에 쓰는 이미지 |
| 프로필 헤더 | 프로필 상단 배경 |
| 프로필 소개 | 프로필 페이지 소개글 |
| 프로필 주소 | 사용자 목록·프로필의 프로필 버튼. 비우면 버튼 숨김 |

보기 설정(스레드 보기)도 이 화면에서 정합니다.

## 스킨 업로드

타임라인 스킨을 tar.gz로 설치합니다. 설치한 이름은 생성/수정 화면의 **스킨**에서 고릅니다.

---



## 게시판과의 차이

타임라인은 실시간 폴링·DM·이미지 슬롯이 기본입니다. 일반 게시판(300)과 테이블이 다릅니다. 표시 이름·헤더·썸네일은 캐릭터가 아니라 타임라인 사용자 프로필입니다. 모듈을 붙이려면 그 모듈이 타임라인 훅을 지원해야 합니다.
