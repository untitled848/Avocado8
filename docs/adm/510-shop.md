# 510 · 상점/화폐

**메뉴 위치:** 관리자 → 상점/화폐

사이트 **화폐 이름**, 캐릭터에게 찍힌 **화폐 내역**, **상점 진열**, **구매 기록**입니다. 아이템 원장은 [아이템 관리](500-item.md) 입니다.

상점 페이지 접근 권한은 [통합 권한관리](100-community.md#통합-권한관리) 입니다.

---

## 화폐 관리

**경로:** `/adm/point_list.php`  
**메뉴:** 상점/화폐 → 화폐 관리 (명칭은 커뮤니티에서 정한 화폐 이름)

### 위쪽 설정

| 항목 | 하는 일 |
|------|---------|
| 화폐 명칭 / 단위 | 화면에 찍히는 이름. **화폐 설정 저장** |
| 화폐(포인트) 기능 사용 | 켜야 지급·차감이 돌아갑니다 |
| 로그인 시 획득 | 하루에 로그인하면 주는 양. 0 이면 없음 |

### 내역 목록

누가 언제 얼마나 받았는지입니다. 검색은 **회원아이디** 또는 **내용**. 줄 체크 후 **선택삭제**.

### 개별회원 화폐 증감

**개별지급** / **전체지급**. 내용 + 금액(빼려면 음수) → **확인**. 여러 캐릭터·아이템까지 같이 주려면 [통합 정산](520-calc.md).

## 상점 관리

**경로:** `/adm/shop_list.php`

상점에 **올려 팔 아이템**입니다. 사용자 화면: `/shop`

이 화면에서 같이 다루는 것:

- **상점 카테고리 관리**: 칩(일반·이벤트 등). **카테고리 저장** 필수
- **상점 출력 옵션**: 페이지당 개수, 한 줄 그리드, 아이템 가로·세로 px, NPC 이미지. **출력 옵션 저장**
- 목록 필터: 시기, 카테고리, 아이템 이름·설명 검색

**진열 추가** 로 아이템·가격·재고·시기를 넣습니다. **진열 시기 일괄 설정** 으로 여러 줄의 시기를 한 번에 바꿉니다. 목록에서 선택수정·선택삭제.

---

## 아이템 구매기록

**경로:** `/adm/order_list.php`

누가 무엇을 샀는지 로그입니다. 캐릭터 이름·아이템 이름으로 검색합니다. 취소용으로 줄을 지울 수는 있어도, 인벤까지 자동으로 되돌리지는 않을 수 있습니다. 회수는 인벤 보유현황과 함께 확인하세요.

---

## 자주 하는 일

1. **화폐 이름 정하기** → 화폐 관리 위쪽 저장 (커뮤니티 설정의 기타 명칭과 별개로 여기가 정본)  
2. **시즌 상점** → 아이템 등록 → 상점 진열 + 출력 시기
