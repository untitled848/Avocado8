# 110 · 시기/디자인 관리

**메뉴 위치:** 관리자 → 시기/디자인 관리

홈페이지 **분위기(디자인·테마)** 와 **프로필 구간(시기)** 을 미리 만들어 두고, 필요할 때 바꾸는 메뉴입니다.

커뮤니티 설정에서 **디자인 관리 사용하지 않음** 이 켜져 있으면 이 메뉴의 색·디자인 설정은 사용자 화면에 안 먹습니다.

---

## 개요


| 이름           | 하는 일                                                           | 관리 화면                                 |
| ------------ | -------------------------------------------------------------- | ------------------------------------- |
| **디자인 프리셋**  | 색·로고·버튼·세계관/문서 메뉴 등 **CSS·화면 값 한 벌**. 사이트·세계관·문서 각각 여러 개 저장 가능 | `/adm/design_form.php` 등 · 페이지 디자인 설정 |
| **테마 프리셋**   | 디자인 프리셋 + 페이지별 테마 폴더 + BGM·폰트 등을 **한 세트**로 묶어 교체               | `/adm/theme_preset_list.php`          |
| **시기**       | 본편·AU·이벤트 등 **구간**을 두고, 그 구간에 쓸 설정을 저장·전환                      | `/adm/config_time.php`                |
| **시기–테마 연동** | 테마 프리셋을 미리 만들어 두면, **시기마다 어떤 프리셋을 쓸지** 지정                      | 시기 관리의 「테마 프리셋」 칸                     |


흐름: **디자인 프리셋을 고친다** → **테마 프리셋에 넣고 슬롯을 고른다** → **시기에 그 테마 프리셋을 연결한다** → (필요 시) **현재 공개 시기** 를 바꾼다.

관리자 상단의 `시기: …` / `테마: …` 는 지금 사이트에 적용 중인 값입니다.

---



## 테마 프리셋

홈페이지 디자인 설정을 여러 패턴으로 저장해 두고, 필요에 따라 통째로 바꿉니다.

예전 아보카도의 **디자인 설정**·**테마** 를 합쳐, **페이지(슬롯)마다 다른 테마** 를 고를 수 있게 한 기능입니다.

### 변경 가능 항목 (일반 · 색/디자인)

기존 디자인 설정과 같습니다. 각 저장본은 **페이지 디자인 설정** 에서 추가·수정합니다.


| 항목         | 설명                                              | 어디서                                               |
| ---------- | ----------------------------------------------- | ------------------------------------------------- |
| 일반 색상/디자인  | 사이트 전역 색·로고·버튼·여백 등                             | `/adm/design_form.php`                            |
| 세계관 디자인    | 디자인 저장본 **또는** 스킨 폴더. 스킨을 쓰면 디자인 저장본 내용은 무시됩니다. | `/adm/world_design_form.php` · `/skin/world/`     |
| 문서 디자인     | 내용관리(기타 문서)용. 위와 같음                             | `/adm/content_design_form.php` · `/skin/content/` |
| 배경음악       | 비우면 커뮤니티 기본 BGM                                 | 테마 프리셋 편집                                         |
| 홈페이지 전체 폰트 | 비우면 기본 폰트                                       | 테마 프리셋 편집                                         |


세계관·문서 스킨은 게시판 스킨과 같이 해당 폴더에 올려 씁니다.

### 변경 가능 항목 (테마 · 슬롯)

예전에는 테마 하나를 고르면 **사이트 전체가** 바뀌었습니다.  
지금은 **슬롯(페이지/영역)마다** 다른 테마 폴더를 지정할 수 있습니다.

프리셋 편집 화면의 **한 번에 모두 적용** 으로, 선택한 테마가 지원하는 슬롯에 한꺼번에 넣을 수 있습니다.


| 슬롯                         | 설명                                                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **기본 세팅**                  | 모든 페이지 골격(헤더·푸터·head.sub·tail.sub). 네 파일이 한 묶음으로 바뀝니다.                                                                      |
| 메뉴                         | 사이트 메뉴                                                                                                                      |
| 인덱스                        | iframe 부모 등 최상위 골격 페이지. 테마에 파일이 없으면 기존 파일이 쓰입니다.                                                                            |
| 인트로 / 메인 / 엔터              | 각 진입·메인 화면                                                                                                                  |
| 로그인                        | 사이트가 닫혀 있을 때 쓰는 로그인 페이지                                                                                                     |
| 마이페이지                      | 테마에 해당 파일이 없으면 기존 스킨이 유지됩니다.                                                                                                |
| 멤버란                        | 목록·프로필 영역. **리뉴얼·AU 시기** 에서는 멤버란 **리스트/프로필 스타일이 그 시기에 맞춰 고정**되는 경우가 있습니다. (예: AU 시기에 「오리지널」 멤버란 URL로 들어가도 스타일은 오리지널 시기를 따름) |
| 상점 / 인벤토리                  | 해당 영역                                                                                                                       |
| 세계관                        | 테마 쪽에 파일이 있으면, 세계관 **스킨을 제외한 기능 쪽**이 덮일 수 있습니다.                                                                             |
| MMB / 기본 / QnA / 정산 게시판 스킨 | 해당 스킨을 쓰는 게시판 스타일이 프리셋과 함께 바뀝니다.                                                                                            |
| outlogin 스킨                | 메인 로그인 전·후 영역                                                                                                               |
| 세계관·문서 기본 스킨               | 디자인에서 「basic」 스킨을 쓸 때, 테마 변경과 함께 스타일이 바뀝니다. 테마에 없으면 기존 유지.                                                                  |


`default` 는 사이트 루트의 기본 파일을 쓴다는 뜻입니다. 선택한 테마에 파일이 없으면 자동으로 기본으로 돌아갑니다.

테마 폴더를 직접 만들거나 배포할 때: [테마 만들기 (제작자용)](../theme/AUTHORING.md)

## 시기

시기에 따른 홈페이지·프로필 설정을 저장해 두고, **현재 공개 시기** 를 바꿔 구간을 전환합니다.

**경로:** `/adm/config_time.php`  
**메뉴:** 시기/디자인 관리 → 시기 관리

멤버는 기본적으로 **현재 공개 시기** 로 설정된 홈페이지를 봅니다.  
관리자는 마이페이지 → 관리자 메뉴의 **시기 미리보기(오버라이드)** 로, 다른 시기 화면을 미리 확인할 수 있습니다.

### 타입


| 타입          | 새 프로필 작성 / 멤버·마이페이지 시기 탭 | 프로필 양식·사이드·클래스 변동 | 시기별 NPC | 화면에 나오는 캐릭터 정보                            | 비고                            |
| ----------- | ------------------------ | ----------------- | ------- | ----------------------------------------- | ----------------------------- |
| **리뉴얼(성장)** | 있음                       | 있음                | 있음      | 그 시기 **및 이후**: 이 시기의 정보                   | **순서 1번** 시기는 항상 리뉴얼·공개·삭제 불가 |
| **AU**      | 있음                       | 있음                | 있음      | **그 시기만** 이 시기 정보. **이후**에는 직전 **리뉴얼** 정보 | AU가 끝나면 본편(직전 리뉴얼) 프로필로 돌아감   |
| **이벤트**     | 없음 (탭에도 안 나옴)            | 없음                | 없음      | 그 시기·이후 모두 **직전 리뉴얼** 정보                  | **테마 프리셋**으로 분위기만 바꿈. 프로필은 유지 |




### 예시 (성장 커뮤)

시기 흐름이  
`A(리뉴얼) → B(이벤트) → C(이벤트) → D(리뉴얼) → E(AU) → F(이벤트)`  
이면 대략 다음과 같습니다.


| 현재 시기         | A         | B       | C     | D         | E         | F         |
| ------------- | --------- | ------- | ----- | --------- | --------- | --------- |
| 구분            | 리뉴얼       | 이벤트(신청) | 이벤트1  | 리뉴얼(성장)   | AU        | 이벤트2      |
| 캐릭터 정보        | A         | A와 동일   | A와 동일 | D         | E         | D와 동일     |
| 멤버/마이페이지 시기 탭 | A         | A       | A     | A / D     | A / D / E | A / D / E |
| 프로필 양식 예      | 외모·성격·학년… | A와 동일   | A와 동일 | 외모·성격·직업… | 외모·성격·능력… | D와 동일     |
| 사용 사이드/클래스    | (A용)      | A와 동일   | A와 동일 | (D용)      | (E용)      | D와 동일     |
| NPC           | (A용)      | A와 동일   | A와 동일 | (D용)      | (E용)      | D와 동일     |


그 밖에 시기별로 걸러지는 항목(상점 진열, 슬라이드 등)은 아래 「시기에 따라 달라지는 항목」을 보세요.

### 공개 / 비공개 / 미사용

멤버가 보는 기본 화면은 **현재 공개 시기** 입니다.  
**비공개·미사용** 은 주로 AU·리뉴얼에서 **프로필을 미리 쓸 수 있는지** 가 다릅니다. 이벤트에서는 거의 같은 역할입니다.


| 공개      | (해당 시기) 공지 등 열람 | 멤버 리스트·시기 탭 | 프로필 열람·시기 탭 | 프로필 수정 | 비고                                                                                              |
| ------- | --------------- | ----------- | ----------- | ------ | ----------------------------------------------------------------------------------------------- |
| **공개**  | 가능              | 가능          | 가능          | 가능     | 1) **현재 시기** 는 비공개/미사용이어도 접근 가능. 2) 접근 불가 시기로 들어가면 **현재 시기** 로 이동. 3) **1번(기본) 시기** 는 항상 공개 고정. |
| **비공개** | 관리자만            | 관리자만        | **내 캐릭터만**  | 본인 가능  | 성장·AU **사전 작성** 기간에 자주 씀                                                                        |
| **미사용** | 관리자만            | 관리자만        | 관리자만        | 관리자만   | 일반 멤버는 열람·수정 불가                                                                                 |




### 시기에 따라 달라지는 항목


| 항목               | 설명                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------- |
| **테마 프리셋**       | 위 「테마 프리셋」 참고. 시기마다 다른 세트를 연결할 수 있습니다.                                                  |
| **상점 진열 아이템**    | 각 설정 폼에서 **출력 시기** 를 지정하면 그 시기에만 나갑니다.                                                  |
| **메인 슬라이드**      | 출력 시기 지정 (커뮤니티 설정 → 메인슬라이드)                                                             |
| **인트로**          | 출력 시기 지정                                                                                |
| **공지사항**         | 출력 시기 지정. *관련 기능은 계속 다듬는 중입니다.*                                                         |
| **활성 사이드 / 클래스** | `/adm/side_list.php`, `/adm/class_list.php` 하단. 신규 프로필에서 고를 수 있는 목록·해당 시기 멤버 출력이 달라집니다. |
| **활성 NPC**       | `/adm/character_list.php` → NPC 탭 상단. 시기마다 보일 NPC를 고릅니다.                                |




### 시기 관리 화면에서 할 일


| 칸      | 하는 일                        |
| ------ | --------------------------- |
| 순서     | 시기 탭에 나오는 순서. 1번은 고정.       |
| 이름     | 화면에 찍히는 이름.                 |
| 공개     | 공개 / 비공개 / 미사용              |
| 타입     | 리뉴얼 / AU / 이벤트 (1번은 리뉴얼 고정) |
| 테마 프리셋 | `(글로벌)` 또는 특정 프리셋           |
| 삭제     | 1번 외. 체크 후 **전체 저장**        |
| 자세히    | 그 시기의 상세(프로필 항목 등)          |


**현재 공개 시기:** 주소에 `?time=` 없이 들어올 때 쓰는 기본 시기입니다.  
**글로벌 기본 테마 프리셋:** 시기에 프리셋을 안 붙였을 때 쓰는 세트입니다. `(없음)` 이면 시스템 기본(`#1 default`)입니다.

**＋ 새 시기 추가** 후 순서(2 이상)·이름·공개·타입을 넣고 **전체 저장** 합니다.

## 페이지 디자인 설정

**경로:** `/adm/design_form.php` (사이트) · `world_design_form.php` (세계관) · `content_design_form.php` (문서)  
**메뉴:** 시기/디자인 관리 → 페이지 디자인 설정

위쪽 탭:


| 탭   | 하는 일                             |
| --- | -------------------------------- |
| 사이트 | 전역 색·폰트·버튼·여백                    |
| 세계관 | 세계관 페이지 메뉴·배경 (또는 스킨 사용 시 스킨 우선) |
| 문서  | 내용관리(기타 문서) 페이지 디자인 (또는 스킨)      |




### 저장본 다루기

- **현재 편집 중**: 어떤 저장본을 고치는지 (예: `#2 white`).
- **전환**: 다른 저장본으로 편집 대상을 바꿉니다.
- **새 디자인 만들기 / 현재 디자인 복제 / 이름 변경 / 삭제**
- **JSON 내보내기·가져오기**: 저장본을 파일로 옮기거나 가져옵니다.

이 저장본이 어떤 테마 프리셋에 붙어 있는지는 화면 안내에 나옵니다. 시기에 쓰려면 [테마 프리셋](#테마-프리셋-설정) 에서 세트에 넣습니다.

**확인** 을 눌러야 색이 저장됩니다. 오른쪽 **실시간 미리보기** 와 **실제 페이지** 링크로 확인하세요.

### 사이트 탭 안 구역


| 구역       | 예                              |
| -------- | ------------------------------ |
| 화면       | 헤더 사용, 로고(PC/모바일), 배경 이미지·색·반복 |
| 메뉴       | 메뉴 색·폰트                        |
| 버튼       | 기본/강조 버튼                       |
| 테이블(게시판) | 목록 표 스타일                       |
| 로드비 디자인  | 로딩 화면                          |
| 기타       | 나머지 CSS 항목                     |


로고는 커뮤니티 설정의 파비콘과 별개입니다.

## 테마 프리셋 설정

**경로:** `/adm/theme_preset_list.php`  
**메뉴:** 시기/디자인 관리 → 테마 프리셋 설정

위쪽 탭: **테마 프리셋** / **사이트 프리셋** / **세계관 프리셋** / **문서 프리셋** / **테마 업로드**

### 테마 프리셋 (세트)

카드 표시:

- **활성**: 지금 사이트에 적용 중
- **글로벌**: 시기 매핑이 없을 때 기본
- **기본**: 시스템 `#1` (지우기 어렵습니다)

카드에 디자인(색 저장본), 세계관, 문서, BGM, 연결된 시기, 슬롯 덮어쓰기가 요약됩니다.

- **편집**: 슬롯별 테마 폴더, 디자인 저장본, BGM·폰트를 고릅니다.
- **미리보기**: 그 세트로 사이트 모습을 봅니다 (`?preset=`).
- 아래 이름으로 **＋ 새 프리셋 추가**

글로벌 기본은 이 화면 위쪽에서도 바꿀 수 있습니다.

### 사이트 / 세계관 / 문서 프리셋 탭

색·메뉴 저장본 **목록**입니다. 내용을 고치려면 각각 페이지 디자인 설정의 사이트·세계관·문서 탭으로 갑니다. 시기에 쓰려면 **테마 프리셋** 탭에서 세트에 넣습니다.

### 테마 업로드

테마 **폴더**를 `.tar.gz` 로 설치합니다. 설치한 폴더는 프리셋 편집에서 슬롯별로 고를 수 있습니다. **색은 테마 폴더가 아니라 페이지 디자인 설정** 입니다.

## 자주 쓰는 운영 방법



### 1. 성장(리뉴얼) 커뮤니티

- **리뉴얼** 타입으로 성장 프로필을 만듭니다. 관계·인벤토리 등은 이어지고, 성장 시기가 지나면 **성장 후 프로필**이 나옵니다.
- 작성 기간에는 성장 시기를 **비공개**로 두면, 멤버가 **자기 캐릭터 프로필만** 미리 쓸 수 있습니다.
- 공개 시점에 시기를 **공개**로 바꾸고, 필요하면 **현재 공개 시기**를 그 리뉴얼로 맞춥니다.



### 2. AU 프로필

- **AU** 타입으로 AU 전용 프로필을 만듭니다. AU가 끝나면 표시는 **직전 리뉴얼** 쪽으로 돌아갑니다.
- 사전 안내 기간에는 AU 시기를 **비공개**로 두어 미리 작성하게 할 수 있습니다.



### 3. 이벤트별 분위기 원클릭 변경

1. 이벤트용 **테마 프리셋**을 미리 만듭니다. (BGM, 배경, 슬롯 스킨 등)
2. **이벤트** 시기를 만들고 그 프리셋을 연결합니다.
3. 공지·메인슬라이드·상점 진열 등을 **출력 시기**에 맞춰 미리 등록합니다.
4. 이벤트 시작 때 **현재 공개 시기**만 이벤트로 바꿉니다.
5. 관리자는 마이페이지 관리자 메뉴의 **시기 미리보기**로 미리 확인합니다.
6. 끝나면 현재 공개 시기를 본편(리뉴얼)로 되돌립니다.



### 짧은 체크리스트

1. **오픈 전 기본 색만 바꾸기** → 페이지 디자인에서 저장본 수정 → 테마 프리셋 `#1`이 그 저장본을 가리키는지 확인
2. **이벤트만 다른 테마** → 프리셋 추가 → 이벤트 시기 연결 → 현재 공개 시기를 이벤트로 변경
3. **시즌 종료** → 현재 공개 시기를 본편(리뉴얼)로 복귀
