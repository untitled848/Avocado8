# 500 · 아이템/타이틀

**메뉴 위치:** 관리자 → 아이템/타이틀

아이템 **원장**(무엇을 팔고 뽑을지), **뽑기 확률**, **조합 레시피**, 누가 무엇을 가졌는지, **타이틀(칭호)** 을 다룹니다. 상점에서 파는 것은 [상점/화폐](510-shop.md) 입니다. 여기서는 아이템 자체를 정의합니다.

---

## 아이템 관리

**경로:** `/adm/item_list.php`  
**메뉴:** 아이템/타이틀 → 아이템 관리

기능 분류는 이 화면 위 **아이템 카테고리(기능) 관리** 칩입니다. 드래그로 순서, ×로 삭제, 글자를 눌러 이름을 바꿉니다. **모듈에서 추가된 기능** 은 잠겨 있어 여기서 못 지웁니다. **카테고리 저장** 을 눌러야 칩이 반영됩니다.

목록은 **아이템 기능** 필터(일반, 프로필수정, 뽑기, 펫알 등)로 걸러 볼 수 있습니다. **아이템 추가** 로 원장을 만듭니다.

| 구분 | 예 |
|------|-----|
| 카테고리 | 일반, 개인, 출석 (모듈이 더 넣을 수 있음) |
| 기능(타입) | 위에서 정한 칩 + **뽑기** + 모듈 타입 |
| 사용 | Y/N |
| 이미지·설명 | 상점·인벤에 보임 |

뽑기용 아이템은 타입을 뽑기로 두고, 실제 당첨 목록은 [뽑기 관리](#뽑기-관리) 에서 연결합니다.

---

## 뽑기 관리

**경로:** `/adm/explorer_list.php`

**화면 제목:** 아이템 뽑기 관리

어떤 아이템을 뽑기로 썼을 때 **무엇이 나오는지** 확률 목록입니다. 탭: **뽑기 설정 목록** / **뽑기 등록**.

등록: **뽑기 아이템**(기능이 ‘뽑기’인 아이템만 검색) + **결과 아이템** + 확률 구간. 목록에서 선택수정·선택삭제.

뽑기용 아이템은 먼저 [아이템 관리](#아이템-관리) 에서 기능을 뽑기로 둡니다.

---

## 레시피 관리

**경로:** `/adm/recipi_list.php`

재료 아이템을 넣고 **결과 아이템**을 만드는 조합식입니다. 탭: **레시피 목록** / **레시피 정보 입력**.

재료는 최대 3종입니다. 검색은 **아이템 속성이 레시피 재료**인 것만 나옵니다. 목록에서 선택수정·선택삭제.

---

## 아이템 보유현황

**경로:** `/adm/inventory_list.php`

캐릭터가 가진 아이템 행입니다. 화면 제목: **아이템 보유현황 관리**.

- **아이템 지급**: 개별지급 / 전체지급. 캐릭터·아이템·수량 후 **확인**
- **아이템 보유 목록**: 캐릭터 이름·아이템 이름으로 검색. **선택삭제** 로 줄 제거

여러 종류를 한 번에 주려면 [통합 정산](520-calc.md) 이 편합니다. 전체지급은 모든 캐릭터에게 들어가므로 실수하지 마세요.

---

## 타이틀 관리 / 보유타이틀 관리

**경로:** `/adm/title_list.php`, `/adm/title_has_list.php`

- **타이틀 관리**: 칭호 이름, 타입(이미지/텍스트/둘다), 이미지, 텍스트 CSS, 사용 여부. 탭: 목록 / 등록
- **보유타이틀 관리** (`title_has_list.php`): **타이틀 지급**(개별/전체) + **타이틀 보유 목록**. 검색 후 **선택삭제** 로 회수

일괄 지급은 [통합 정산](520-calc.md) 에서도 됩니다. 프로필에 타이틀을 보이게 하려면 [프로필 양식](400-character.md) 의 **타이틀 사용** 을 켭니다.

---

## 자주 하는 일

1. **상점 아이템** → 여기서 아이템 등록 → 상점 관리에서 진열·가격  
2. **뽑기** → 아이템 타입 뽑기 → 뽑기 관리에 결과 목록
