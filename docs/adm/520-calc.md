# 520 · 통합 정산

**메뉴 위치:** 관리자 → 통합 정산

여러 캐릭터에게 **아이템·타이틀·화폐·경험치**를 한 번에 줍니다. 주간 정산, 이벤트 보상, 신청 게시판과 맞춰 쓸 수 있습니다.

---

## 일괄 정산

**경로:** `/adm/calc_form.php`  
**메뉴:** 통합 정산 → 일괄 정산  
**화면 제목:** 통합 정산

순서:

1. **대상**
   - 전체 / 진영별 / 분류(직업)별 / 직접 검색
   - **NPC 포함** 체크 시에만 NPC도 들어갑니다
   - 진영·분류 목록은 **현재 시기** 기준입니다
2. **줄 것 (지급 항목)**
   - **직접 지정**: 종류(아이템/타이틀/화폐/경험치) → 이름 검색 → 수량 → **추가**
   - **프리셋 사용**: [정산 프리셋](#정산-프리셋) 에 묶어 둔 묶음
3. **정산 내용**
   - 내역에 남는 메모 (예: 4월 운영 보상)
4. **지급**

지급 전 대상 인원과 항목을 다시 보세요. 잘못 주면 인벤·경험치를 하나씩 고쳐야 합니다.

---

## 정산 프리셋

**경로:** `/adm/calc_preset_list.php`

자주 쓰는 보상 묶음을 저장합니다. **새 프리셋**에서 이름, 항목, 정렬을 정합니다.

**정산 신청** 이 켜진 프리셋은 `calculate` 스킨 게시판의 신청 글쓰기 드롭다운에 나옵니다. 신청 글을 받은 뒤 일괄 정산에서 같은 프리셋으로 지급하는 흐름입니다.

---

## 자주 하는 일

1. **주간 활동 보상** → 프리셋에 아이템·경험치 묶어 두기 → 대상 전체 또는 진영 → 지급  
2. **신청제 정산** → 프리셋에 정산 신청 체크 → 게시판 스킨 calculate → 신청 확인 후 일괄 지급
