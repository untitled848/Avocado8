# 310 · 세계관/공지/문서

**메뉴 위치:** 관리자 → 세계관/공지/문서

사용자에게 보여주는 **설정집(세계관)**, **공지**, **기타 고정 문서**를 만듭니다. 디자인(색·메뉴 배경)은 [시기/디자인](110-design.md) 의 세계관·문서 탭입니다.

---

## 세계관 문서 관리

**경로:** `/adm/world_list.php`  
**메뉴:** 세계관/공지/문서 → 세계관 문서 관리  
**화면 제목:** 세계관 페이지 관리

세계관 본문 페이지 목록입니다. **페이지 추가** 로 제목·내용을 만듭니다. 각 줄에서 수정, **보기**(사용자 화면), 삭제.

**세계관 디자인 설정** 은 색·배경을 고치는 화면으로 갑니다.

사용자 URL: `/world/?wo_id=…` (메인 세계관은 `/world`)

---

## 세계관 메뉴 관리

**경로:** `/adm/world_menu_list.php`  
**메뉴:** 세계관/공지/문서 → 세계관 메뉴 관리  
**화면 제목:** 세계관 메뉴 구성

세계관 페이지 **왼쪽(또는 테마가 정한 위치) 메뉴 트리**입니다.

- **+ 메인 메뉴 추가** 로 1단을 만들고, 그 아래 하위 메뉴를 붙입니다.
- 각 항목에 이름, 연결할 세계관 페이지, 아이콘 이미지를 지정합니다.
- 드래그로 순서를 바꿉니다.
- **저장** 을 눌러야 반영됩니다.

바로가기: **[페이지 목록]** / **[페이지 목록 관리]** (문서 목록), **[세계관 디자인 설정]** (색·배경). 페이지가 없으면 먼저 [세계관 문서](#세계관-문서-관리) 에서 만드세요.

---

## 공지사항 관리

**경로:** `/adm/notice_list.php`  
**메뉴:** 세계관/공지/문서 → 공지사항 관리

사이트 공지 글 목록입니다. 사용자 화면은 `/notice`.

이 화면에서 같이 다루는 것:

- **공지사항 카테고리 관리**: 칩(공지·이벤트 등). 드래그로 순서, ×로 삭제. **카테고리 저장** 필수
- **공지 목록 그리드 설정**: **일반 목록** / **그리드 카드**. 따로 **저장**
- 목록 위 **카테고리 필터**

**공지 추가** 로 글을 만듭니다. 제목, 본문, 시기, 카테고리. 줄의 **보기**는 사용자 화면, **수정**은 편집.

일괄: **선택 사용 / 사용해제 / 고정 / 고정해제 / 삭제**. **문서 디자인 설정** 으로 공지 페이지 모양을 고칩니다.

---

## 기타 문서 관리

**경로:** `/adm/contentlist.php`  
**메뉴:** 세계관/공지/문서 → 기타 문서 관리  
**화면 제목:** 내용관리

이용약관, 안내 페이지처럼 **고정 문서**입니다. 메뉴/메인 본문(`site_menu`, `site_main`)도 이 테이블을 쓰지만, 편집은 [메뉴/메인화면](100-community.md#메뉴메인화면) 에서 합니다.

**내용 추가** 로 `co_id`(영문 코드)·제목·본문을 만듭니다. **문서 디자인 설정** 으로 그 페이지 모양을 고칩니다.

---

## 자주 하는 일

1. **설정집 오픈** → 세계관 페이지 여러 개 작성 → 메뉴 관리에서 트리로 묶기 → `/world` 확인  
2. **공지 올리기** → 공지사항 관리에서 글 추가, 필요하면 시기 지정
