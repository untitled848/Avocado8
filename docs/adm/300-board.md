# 300 · 게시판 관리

**메뉴 위치:** 관리자 → 게시판 관리

게시판 **그룹**(폴더), **게시판** 자체, **이모티콘**을 다룹니다. 글 목록·읽기·쓰기 권한은 게시판 수정 화면과 [통합 권한관리](100-community.md#통합-권한관리) 양쪽에서 바꿀 수 있습니다.

---

## 게시판 그룹/설정

**경로:** `/adm/boardgroup_list.php`  
**메뉴:** 게시판 관리 → 게시판 그룹/설정  
**화면 제목:** 게시판그룹설정

### 위쪽: 모든 게시판 기본값

**게시판 기본 설정 / 기본 스킨 설정** 을 펼치면 사이트 공통 값이 있습니다. 각 게시판에서 따로 정하면 그 값이 이깁니다.

| 항목 | 하는 일 |
|------|---------|
| 한 페이지당 줄 수 | 목록에 몇 줄인지 |
| 페이지 표시 수 | 페이지 번호 몇 개 |
| 글쓰기 간격 | 같은 사람이 글을 다시 쓰기까지 초 |
| 검색 단위 | 검색이 한 번에 훑는 글 수 |
| 새창 링크 | `_blank` 등 |
| 이미지·동영상 확장자 | 첨부 허용 확장자. `\|` 로 구분 |
| 단어 필터링 | 금지 단어 |

**기본 설정 저장** 을 따로 눌러야 합니다.

### 그룹 목록

그룹은 게시판을 묶는 단위입니다. **게시판그룹 추가** 로 만듭니다.

목록에서 제목, 그룹관리자, 출력 순서, 접속기기(모두/PC/모바일)를 고치고 **선택수정** 합니다. **접근사용** 을 켜면 지정한 회원만 그 그룹의 게시판에 들어갑니다.

**선택삭제** 는 그룹을 지웁니다. 안에 게시판이 있으면 먼저 비우거나 옮기세요.

## 게시판 관리

**경로:** `/adm/board_list.php`  
**메뉴:** 게시판 관리 → 게시판 관리

탭: **게시판 목록** / **스킨 업로드** (`tar.gz` 로 스킨 설치).

- **게시판 추가**: 새 TABLE 이름과 설정을 만듭니다.
- 목록에서 그룹, 스킨, 제목, 읽기/쓰기/댓글/다운 포인트를 바로 고칠 수 있습니다.
- **수정**: 상세 설정. **복사**: 비슷한 게시판을 복제.

**선택수정 / 선택삭제**. 삭제는 글 테이블까지 지워질 수 있으니 확인하세요.

### 게시판 수정 화면 (`board_form.php`)

주요 구역:

| 구역 | 하는 일 |
|------|---------|
| 기본 | TABLE 이름(영문), 제목, 그룹 |
| 권한 | 목록/읽기/쓰기/답변/댓글 등급 |
| 기능 | 비밀글, 에디터, 업로드 등 |
| 스킨 | 스킨 디렉토리. `mmb` 는 커뮤니티 로그형 |
| 스킨 설정 | 그 스킨 전용 옵션이 있으면 여기 |
| 모듈 | **이 게시판에서** 켤 기능. 모듈 관리에서 켠 뒤, 여기서 게시판마다 다시 켭니다. 스킨이 훅을 안 주면 경고가 납니다. |

수정 화면에서 **게시판 바로가기**, **게시판복사**, 썸네일 삭제가 있습니다.

권한만 한꺼번에 바꾸려면 [통합 권한관리](100-community.md#통합-권한관리) 가 빠릅니다.

## 이모티콘 관리

**경로:** `/adm/emoticon_list.php`  
**메뉴:** 게시판 관리 → 이모티콘 관리

글·댓글·쪽지에서 `:코드:` 형태로 쓰는 이미지를 등록합니다. 쪽지에서 쓰려면 [호출/쪽지 설정](100-community.md#호출쪽지-설정) 의 **쪽지 이모티콘 사용** 도 켜야 합니다.

위쪽 **유저 신청 정책**: 신청불가 / 관리자 승인 / 자동승인. **저장** 을 눌러야 반영됩니다.

아래 **이모티콘 등록**: 명령어 + 이미지 → **확인**. 목록에서 선택수정·선택삭제.

---

## 자주 하는 일

1. **로그용 게시판** → 그룹 확인 → 게시판 추가, 스킨 `mmb` → 모듈 탭에서 탐색/조합 등 필요한 것만 켜기  
2. **스킨 파일이 없음** → 스킨 업로드 탭에서 tar.gz 설치 후, 게시판 설정의 스킨 디렉토리에서 고름
