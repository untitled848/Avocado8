# 410 · 랭킹/경험치/스탯

**메뉴 위치:** 관리자 → 랭킹/경험치/스탯

화면에 찍히는 **랭킹·경험치 이름**은 [커뮤니티 설정](100-community.md) 의 기타 항목명입니다. 이 메뉴는 **단계 표**, **지급 내역**, **스탯 종류**입니다.

---

## 랭킹 설정 관리

**경로:** `/adm/level_list.php`  
**메뉴 이름:** `{랭킹명칭} 설정 관리`

경험치가 얼마일 때 어떤 랭킹(레벨)인지 **구간표**입니다. 탭: **랭킹 설정 목록** / **랭킹 설정 등록**.

등록 칸:

- **랭킹명**
- **요구경험치** (이 값 이상이면 해당 랭킹)
- **추가스텟포인트** (그 랭킹에 도달하면 더 주는 스탯 포인트)

목록에서 선택수정·선택삭제. 숫자가 클수록 높은 단계가 되도록 경험치를 올리는 식으로 넣습니다.

---

## 경험치 관리

**경로:** `/adm/exp_list.php`

캐릭터에게 준 경험치 **내역**과 수동 지급입니다.

위쪽 **경험치 명칭 / 단위 설정** 을 저장합니다 (예: 경험치 / exp).

**경험치 지급/회수**

- **개별지급**: 캐릭터 이름 + 지급 내용 + 경험치(빼려면 음수) → **확인**
- **전체지급**: 모든 캐릭터에게 같은 양

**경험치 내역**: 캐릭터이름·오너이름·내용으로 검색. 줄 체크 후 **선택삭제** (내역만 지울 수 있음. 실제 경험치가 돌아가는지는 지급 화면에서 확인).

글쓰기 포인트와는 별개입니다. 여러 명에게 아이템까지 같이 주려면 [통합 정산](520-calc.md) 이 편합니다.

---

## 스탯 관리

**경로:** `/adm/status_list.php`

힘·지능처럼 **능력치 종류**를 만듭니다. 화면 제목은 **스탯설정 관리**.

- **최초 스탯 포인트**: 캐릭터 생성 시 나눠 쓸 포인트. 위쪽에서 저장합니다.
- **스탯 설정 목록**: 이름, 최대/최소, 순서, 사용. **선택수정 / 선택삭제**
- **스탯 설정 등록**: 스탯명, 최대값, 최소값, 도움말, 순서, **기준계산(최대값 기준으로 출력)**

새 스탯을 등록하면 프로필·캐릭터 폼에 칸이 생깁니다. 모듈(전투 등)이 자기 스탯을 쓰는 경우도 있습니다. 코어 스탯과 섞이지 않게 이름을 구분하세요.

## 자주 하는 일

1. **레벨 테이블 짜기** → 랭킹 설정에 구간을 낮은 경험치부터 등록  
2. **이벤트 경험치** → 정산으로 일괄 지급하거나, 경험치 관리에서 한 명씩
