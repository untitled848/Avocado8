# 100 · 커뮤니티 설정

**메뉴 위치:** 관리자 → 커뮤니티 설정

사이트 이름·로고, 메뉴/메인 본문, 메인 슬라이드, 인트로, 알림(호출/쪽지), 공개·권한을 다룹니다. 예전에는 `환경설정` 한 화면에 모여 있었고, 지금은 분야별로 나뉘었습니다.

페이지 위쪽 안내 상자에 다른 메뉴로 옮겨 간 항목이 적혀 있습니다. 공개 여부·캐릭터 생성은 **통합 권한관리**, 화폐 이름은 **상점/화폐**, 스탯 초기값은 **스탯 관리** 입니다.

---

## 커뮤니티 설정

**경로:** `/adm/community_form.php`  
**메뉴:** 커뮤니티 설정 → 커뮤니티 설정

섹션이 여러 개입니다. 각 섹션마다 **확인** 이 있습니다. 눌러야 그 내용이 저장됩니다. (한 폼이라 어느 확인을 눌러도 전체가 제출됩니다.)

### 기본환경


| 항목             | 하는 일                                                 |
| -------------- | ---------------------------------------------------- |
| 최고관리자          | 사이트 최고관리자 회원 아이디. 드롭다운에서 고릅니다.                       |
| 관리자 아이콘        | 관리자 표시용 아이콘 파일. 이미 있으면 미리보기와 **현재 아이콘 삭제** 가 보입니다.   |
| 홈페이지 제목        | 브라우저 탭·사이트 제목. 필수입니다.                                |
| 사이트설명          | 짧은 설명. SNS 미리보기 등에 쓰입니다.                             |
| 파비콘            | `.ico` 파일을 올리거나, 외부 URL을 넣습니다.                       |
| 사이트이미지         | SNS에 링크를 올릴 때 나오는 썸네일. 권장 290×160. 파일 업로드 또는 외부 URL. |
| 배경음악           | 유튜브 **재생목록** 주소의 `list=` 뒤 아이디만 넣습니다.                |
| 디자인 관리 사용하지 않음 | 켜면 관리자의 디자인 설정(110 메뉴)을 쓰지 않고, 테마 파일을 직접 고칩니다.       |
| 에디터 선택         | 게시판·가입 등에서 쓸 글 편집기. `사용안함` 또는 설치된 에디터 이름.            |




### 기타 항목명

화면에 찍히는 **이름만** 바꿉니다. 기능을 켜고 끄는 곳이 아닙니다.


| 항목          | 하는 일                             |
| ----------- | -------------------------------- |
| 경험치 명칭 / 단위 | 예: 경험치 / exp. 메뉴 이름에도 반영됩니다.     |
| 랭킹 명칭       | 예: 랭킹. 비우면 기본 이름이 쓰입니다.          |
| 진영(선택A) 명칭  | 프로필에 쓰는 이름. **비우면 프로필에 안 나옵니다.** |
| 직업(선택B) 명칭  | 위와 같습니다.                         |


진영·직업의 실제 목록은 [캐릭터/프로필](400-character.md) 에서 만듭니다.

### 여분 필드 (cf_1 ~ cf_10)

코어가 안 쓰는 칸은 자유롭게 값을 넣을 수 있습니다. 이미 쓰이는 칸은 라벨에 용도가 적혀 있습니다.

- `cf_10`: MMB 게시판 목록 **상단 한 줄 공지**(롤링). HTML 일부를 넣을 수 있습니다.

`cf_1`, `cf_2` 등은 권한·기능 스위치로 쓰이므로 이 화면의 여분 목록에는 안 나옵니다. 계정/캐릭터 허용은 **통합 권한관리** 입니다.

### 접속 제한


| 항목      | 하는 일                                                    |
| ------- | ------------------------------------------------------- |
| 접근가능 IP | 여기에 적힌 IP만 사이트를 엽니다. 비우면 제한 없음. `123.123.+` 형식, 줄마다 하나. |
| 접근차단 IP | 적힌 IP는 들어올 수 없습니다.                                      |


**접근가능 IP를 잘못 넣으면 본인까지 막힐 수 있습니다.** 넣을 때는 자기 IP를 꼭 포함하세요.

### 레이아웃 추가설정


| 항목             | 하는 일                                                       |
| -------------- | ---------------------------------------------------------- |
| 추가 script, css | 사용자 화면 HTML의 `</HEAD>` 바로 위에 붙습니다. **관리자 화면에는 적용되지 않습니다.** |
| 추가 폰트 (head)   | Google Fonts 같은 `<link>` / `<style>` 를 `<HEAD>` 안에 넣습니다.   |

## 메뉴/메인화면

**경로:** `/adm/viewer_form.php`  
**메뉴:** 커뮤니티 설정 → 메뉴/메인화면  
**화면 제목:** 화면 설정

에디터로 **메뉴 영역**과 **메인 화면** HTML을 직접 씁니다. PC / 모바일 칸이 나뉩니다. 모바일을 비우면 PC 내용이 나갑니다.

내용은 `site_menu`, `site_main` 문서에 저장됩니다. 아래 **확인** 을 눌러 저장합니다.

### 특수 코드

본문에 아래 글자를 그대로 넣으면 해당 기능이 출력됩니다. 모양을 바꾸려면 오른쪽 파일 위치의 템플릿을 고쳐야 합니다.


| 코드                 | 하는 일                        |
| ------------------ | --------------------------- |
| `{{LOGIN}}`        | 로그인 링크. **비회원일 때만** 보입니다.   |
| `{{LOGOUT}}`       | 로그아웃 링크. **회원일 때만** 보입니다.   |
| `{{JOIN}}`         | 회원가입 링크. 비회원일 때만 보입니다.      |
| `{{MYPAGE}}`       | 마이페이지 링크. 회원일 때만 보입니다.      |
| `{{OUTLOGIN}}`     | 로그인 상자. 로그인 전/후 스킨이 다릅니다.   |
| `{{VISUAL_SLIDE}}` | [메인슬라이드](#메인슬라이드) 에 등록한 배너. |
| `{{BGM}}`          | 배경음악 버튼. **모바일에서는 안 나옵니다.** |


메인에 슬라이드를 쓰려면 본문에 `{{VISUAL_SLIDE}}` 가 들어 있어야 합니다.

## 메인슬라이드

**경로:** `/adm/banner_list.php`  
**메뉴:** 커뮤니티 설정 → 메인슬라이드

메인 화면 슬라이드 이미지 목록입니다. 없을 때는 `자료가 없습니다.` 입니다.

- **메인슬라이드 추가**: 한 장 등록
- **출력 시기 일괄 설정**: 여러 장의 **출력 시기**만 한꺼번에 바꿉니다.

목록 칸: ID, 이미지, 대체텍스트, 시작/종료일시, 출력시기, 출력순서, 관리(수정·삭제).

### 추가·수정 폼

**경로:** `/adm/banner_form.php`


| 항목               | 하는 일                                                     |
| ---------------- | -------------------------------------------------------- |
| 배너 이미지 / 모바일 이미지 | 파일 업로드 또는 외부 URL. 모바일을 비우면 PC 이미지를 씁니다.                  |
| 대체텍스트            | 이미지 설명(접근성).                                             |
| 링크               | 클릭 시 이동 주소. 기본값 `http://` 는 링크 없음으로 취급됩니다.               |
| 새창               | 사용안함 / 사용(새 탭) / 팝업사용                                    |
| 시작일시 · 종료일시      | 이 기간에만 나갑니다. **오늘**, **오늘+31일** 체크가 있습니다.                |
| 출력 순서            | 숫자가 **작을수록** 먼저 나갑니다.                                    |
| 출력 시기            | **전체 시기 (all)** 이면 모든 시기에 나갑니다. 특정 시기만 체크하면 그 시기에만 나갑니다. |


`{{VISUAL_SLIDE}}` 가 메인에 있어야 사용자 화면에 보입니다.

### 출력 시기 일괄 설정

**경로:** `/adm/banner_time_bulk.php`

슬라이드를 체크하고, 적용할 시기를 고른 뒤 저장합니다. **전체 시기** 또는 아무 것도 안 고르면 모든 시기에 출력됩니다.

## 호출/쪽지 설정

**경로:** `/adm/config_call_form.php`  
**메뉴:** 커뮤니티 설정 → 호출/쪽지 설정  
**화면 제목:** 알림 설정

마이페이지의 알림(호출)·쪽지 동작을 정합니다. 맨 아래 **설정 저장** 을 눌러야 반영됩니다.

### 알림 종류

한 줄에 이름, 기본 메모, 기본 링크, 사용, 삭제가 있습니다. **새 종류는 모듈이 등록**합니다. 여기서는 이름·문구·켜고 끄기만 합니다.

시스템 종류(게시판 호출, 쪽지, 선물, 공지, 멘션 등)는 **삭제할 수 없습니다.** 모듈이 만든 종류만 삭제 칸이 있습니다.

링크에 `{tl_table}`, `{wr_id}` 같은 자리 표시가 있으면, 알림이 날 때 실제 글로 바뀝니다.

### 알림 기본 설정


| 항목           | 하는 일                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 확인 간격(초)     | 새 알림을 자동으로 확인하는 주기. 최소 5초. 너무 짧으면 서버 부담이 커집니다.                       |
| 마이페이지 요약 갯수  | 마이페이지 메인에 보여줄 최근 알림 수.                                               |
| 전체보기 페이지당 갯수 | `/mypage/call.php` 한 페이지에 몇 건인지.                                     |
| 알림/쪽지 보관 기간  | 읽은 알림·쪽지를 며칠 뒤 지울지. **0 = 영구 보관.**                                   |
| 쪽지 이모티콘 사용   | 쪽지 본문의 이모티콘 코드를 이미지로 바꿉니다. 이모티콘 자체는 [게시판 관리](300-board.md) 에서 등록합니다. |

## 통합 권한관리

**경로:** `/adm/permission_form.php`  
**메뉴:** 커뮤니티 설정 → 통합 권한관리

사이트 공개 범위, 가입·캐릭터, 주요 페이지, 게시판 권한을 **한 화면**에서 저장합니다. **모든 설정 저장** 한 번으로 반영됩니다.

화면 위 **권한 일괄 수정**에서 운영 단계(가개장 / 신청서 사전등록 / 신청기간 / 합발 준비 / 러닝기간)를 고르면 해당 항목이 폼에 채워집니다. 저장해야 반영됩니다. 지정하지 않은 항목(접근 거부 URL, 게시판 권한, 캐릭터 최대 개수 등)은 그대로 둡니다.

### 사이트 전체


| 항목              | 하는 일                                                                                                                                          |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 공개 범위           | **전체공개**(비회원 포함) / **회원만** / **관리자만**(사이트 잠금)                                                                                                 |
| 접근 거부 시 이동할 URL | 권한 없는 사람을 보낼 주소. 비우거나 그 주소에서도 막히면 `/warning.php`(독립 안내 페이지)로 갑니다. **관리자만** 잠금에서 내부 문서(내용관리)를 넣으면, 그 페이지만 로그인한 비관리자에게 열립니다. 비회원은 로그인 페이지로 갑니다. |


회원만 공개여도 **계정 생성이 허용**돼 있으면 비회원이 가입 페이지에 들어갈 수 있습니다. **관리자만** 잠그면 가입이 허용돼 있어도 가입할 수 없습니다.

### 계정 / 캐릭터


| 항목          | 하는 일           |
| ----------- | -------------- |
| 계정 생성 허용    | 회원가입 on/off    |
| 캐릭터 생성 허용   | 캐릭터 만들기 on/off |
| 아이디 당 최대 N개 | 0 이면 제한 없음     |
| 캐릭터 수정      | 회원 허용 / 관리자만   |




### 페이지별 접근 권한

최소 등급: **방문자 / 일반회원 / 운영자**. 운영자는 설정과 관계없이 항상 들어갑니다.

- 신청자 목록/프로필
- 멤버란
- 쪽지 기능
- 상점 페이지



### 게시판 권한

게시판마다 목록·읽기·쓰기·댓글·다운로드를 **방문자(1) / 일반멤버(2) / 관리자(10)** 로 고릅니다. 게시판 이름을 누르면 그 게시판 상세 설정으로 갑니다.

## 환경설정 (구버전)

**경로:** `/adm/config_form.php`  
**메뉴:** 커뮤니티 설정 → 환경설정 (구버전)

**저장 기능이 없습니다.** 예전 항목이 어디로 옮겼는지만 안내합니다.


| 예전 항목                                 | 지금 위치     |
| ------------------------------------- | --------- |
| 최고관리자, 아이콘, 에디터, IP 제한, 추가 script/css | 커뮤니티 설정   |
| 게시판 기본(글쓰기 간격, 페이지 줄 수 등)             | 게시판 그룹/설정 |
| 화폐 사용, 로그인 시 획득                       | 화폐 관리     |
| 가입 권한, 약관, 닉네임 정책                     | 회원가입 설정   |


북마크가 여기로 오면 표의 바로가기를 쓰세요. 이후 버전에서 메뉴가 없어질 수 있습니다.

## 자주 하는 일

1. **사이트 이름·파비콘 바꾸기** → 커뮤니티 설정 → 기본환경 → 확인
2. **메인에 슬라이드 넣기** → 메인슬라이드에 이미지 등록 → 메뉴/메인화면 본문에 `{{VISUAL_SLIDE}}`
3. **오픈 전 잠그기** → 통합 권한관리 → 공개 범위를 관리자만
4. **가입만 열어 두기** → 공개 범위는 회원만, 계정 생성 허용 체크
