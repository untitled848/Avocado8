# 관리자 페이지 사용자 설명서

사이트 운영자가 `/adm/` 관리 화면을 쓸 때 참고하는 설명서입니다. 메뉴는 왼쪽 사이드바의 **메인 메뉴(00 단위)* 로 나뉩니다.

접속: `http://(사이트주소)/adm/`  
로그인: 최고관리자 계정 (`/adm/login.php`)

---

## 관리자 메인 (`/adm/`)

로그인 후 처음 보이는 화면입니다.

- **시스템 페이지**: 멤버목록, 신청자목록, 마이페이지, 상점, 세계관, 공지를 새 탭으로 엽니다. 사용자 화면이 잘 뜨는지 바로 확인할 때 씁니다.
- **관리자 메뉴**: 아래 메인 메뉴와 같은 링크를 한눈에 보여 줍니다.

상단에는 현재 **시기**, **테마**, 로그아웃, 홈(사용자 화면) 바로가기가 있습니다.

## 공통 사용법

- 폼 아래(또는 각 섹션)의 **확인 / 저장** 을 눌러야 반영됩니다.
- 삭제·끄기·데이터 제거는 확인 창이 뜹니다. 되돌릴 수 없는 작업은 설명서에 **주의** 로 표시했습니다.
- **세션파일 일괄삭제**와 **캐시파일 일괄삭제**는 메뉴를 열면 바로 실행됩니다. 실수로 누르지 마세요.
- 예전 **환경설정** 한 화면은 쓰이지 않습니다. 항목은 분야별 페이지로 옮겨 두었습니다. 안내만 보려면 [환경설정 (구버전)](100-community.md#환경설정-구버전).
